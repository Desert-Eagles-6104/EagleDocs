# EagleDocs

אתר ההכשרות והתיעוד של Desert Eagles 6104, המבוסס על Docusaurus. התוכן בעברית ונמצא ב־`docs/training` וב־`docs/lib`.

## עבודה מקומית

נדרשים Node.js 20 ומעלה ו־npm. מתוך שורש הפרויקט:

```bash
yarn install
```

<a id="local-development"></a>

## פיתוח מקומי

<a id="start-development-server"></a>

### הפעלת שרת הפיתוח

כדי להפעיל את שרת הפיתוח, ודאו שיש הרשאת הרצה לסקריפט `fetch-javadoc.sh`, ואז הריצו:

```bash
chmod +x scripts/fetch-javadoc.sh
npm run start
```

שרת הפיתוח יהיה זמין בכתובת `http://localhost:3000`.

<a id="stop-development-server"></a>

### עצירת שרת הפיתוח

כדי לעצור את שרת הפיתוח, הריצו את הפקודה הבאה:

```bash
kill -9 $(lsof -t -i :3000)
```

<a id="restart-development-server"></a>

### הפעלה מחדש של שרת הפיתוח

כדי להפעיל מחדש את שרת הפיתוח, הריצו את הפקודות הבאות:

```bash
kill -9 $(lsof -t -i :3000)
npm run start
```

<a id="building-the-website"></a>

## בניית האתר

כדי לבנות את הגרסה הסטטית של האתר, הריצו:

```bash
npm run build
npm run serve
```

בדיקת דוגמאות Java דורשת Python ו־JDK 17 ומעלה ב־PATH. היא מחלצת עשר תוכניות מסכמות מהשיעורים, מקמפלת אותן עבור Java 17 ומשווה את הפלט. קטעים חלקיים ודוגמאות שגויות מכוונות אינם נכללים בבדיקה הזאת.

הבנייה יוצרת את `build`. בדקו בדפדפן דף עם טבלה, דף עם תמונות ותרגיל עם רמזים ופתרון, גם ברוחב צר. דוגמאות Java מלאות צריכות להתקמפל ולהציג את הפלט המתועד; בניית האתר לבדה אינה בודקת Java.

## עריכת חומרי לימוד

- תמונות ששייכות לשיעור נשמרות בתיקיית `assets` לידו, עם שם מתאר, טקסט חלופי וקישור לפתיחה בגודל המקורי. אייקונים כלליים נשמרים ב־`static/img`.
- דף פתיחת פרק מסביר את הבעיה שנפתור, את המושגים והקשר ביניהם. תפריט הצד כבר מציג את רשימת השיעורים.
- תרגיל מציין באיזה קובץ עובדים, מה מוסיפים או משנים, איך מריצים ומה בודקים. שינוי תלות או חתימת מתודה דורש עדכון של הקוד הקורא לה.
- הכשרת Java משתמשת בפרויקט אחד; מודלים נפרדים נשמרים בחבילות באותו פרויקט. הכשרת הרובוט משתמשת במאגר רובוט אחד. לפני שינוי שמחליף ניסוי יש לציין איך לשמור ולשחזר אותו.
- דוגמה שגויה או קטע חלקי מסומנים במפורש. תשובה לתרגיל אינה נחשפת מחוץ לאזור הפתרון לפני הניסיון העצמאי.

## Javadoc ופריסה

`npm run prefetch-javadoc` הוא שלב נפרד שדורש Bash, JDK והרשאת SSH למאגר `robot2026`. הוא מוריד קוד ובונה את ה־Javadoc לתוך `static/lib/javadoc`, שזמין באתר ב־`/docs/lib/javadoc/`; אין צורך להפעיל אותו כדי לערוך שיעורים מקומית. בלי השלב הזה, קישורי Javadoc מקומיים עשויים להיות לא זמינים.

הפריסה מוגדרת ב־`.github/workflows` ומתבצעת בדחיפה ל־`main`: התקנת תלויות, הפקת Javadoc, בניית האתר והעתקת הפלט לשרת. אין לדחוף לצורך תצוגה מקומית בלבד.
