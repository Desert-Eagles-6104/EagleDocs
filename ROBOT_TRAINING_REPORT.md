# Robot training implementation

Implemented 30 Hebrew MDX pages: 22 lessons, six section guides, the course home page, and a mentor readiness page. The course evolves one personal template-based project, starting with the existing swerve and progressing to a simulation-only DELib motor mechanism, commands, feedback, vision, hardware preparation, and code review.

## Teaching and navigation

- All 22 lessons reuse the existing ExerciseHelp component with progressive hints and technically explained outcomes. No new component or dependency was introduced.
- New category metadata integrates the robot course into the existing autogenerated sidebar beside Java training. Docusaurus removes numeric prefixes from document IDs; category links use the resolved IDs.
- All Java training files, existing components, global styling, sidebar configuration, manifests and lockfiles remain unchanged.
- Four transparent RGBA PNG diagrams match the existing blue/cyan frames, yellow cards, green accents and Hebrew typography. Portrait layouts were reviewed at 390 px in both themes. Software instructions reference existing installation material and official interface documentation; generated diagrams are not presented as screenshots.
- The downloadable Java file is a student addition, not an existing template mechanism. It uses the actual MotorSubsystemTalon, MasterMotorConstants, MotorSubsystemConfiguration and nested DCMotorMechanismSimConfig APIs. A SIM guard prevents using its example configuration on real hardware.

Required SwerveConstants fields (including speed, hardware, module/drivetrain constants and physical parameters) are uninitialized. This is a source-level startup prerequisite, independent of the cloud download restriction. A template maintainer must complete and validate these settings in a separate robot-template change.

The lesson explicitly adds one in the student's personal repository using the existing mechanism simulation infrastructure. Its full build and physical response remain unverified here because of the dependency-download restriction.

There are no empty lessons, invented library APIs or image placeholders. Remaining work is explicitly identified prerequisite/validation work, not hidden TODO content. No robot-template source additions were made as part of this documentation change.
