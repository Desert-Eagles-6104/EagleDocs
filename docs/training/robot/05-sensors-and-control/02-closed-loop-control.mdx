באחוזי פלט קובעים כמה פלט לבקש; לא קובעים מהירות. בבקרה סגורה מבקשים מהירות, והבקר משתמש במשוב כדי להתקרב אליה. **זו אינה הבטחה שהיעד ניתן להשגה בכל עומס ובכל מתח.**

## 1. משתמשים בפקודת המהירות הקיימת

ב־`RobotContainer` הוסיפו:

```java
import frc.DELib26.subsystems.motorSubsystems.commands.MotorSubsystemSetVelocity;
```

החליפו את binding של North; אל תשאירו גם את פקודת האחוזים על אותו כפתור:

```java
this.trainingFlywheel.ifPresent(flywheel ->
    this.driverController.northButton().whileTrue(
        new MotorSubsystemSetVelocity<>(flywheel, () -> 20.0)));
```

ה־supplier נותן יעד 20 RPS, כלומר 1200 RPM. `setVelocity` מעדכנת את היעד השמור ושולחת `VelocityVoltage` ב־`TalonFXIO`. הבקרה מתבצעת בבקר המנוע המדומה; לא צריך לכתוב `PIDController.calculate` בתוך `robotPeriodic`.

## 2. מה עושים kP ו־kV?

בתצורת התרגיל `kV = 0.12` מספקת פלט משוער לפי המהירות המבוקשת. `kP = 0.1` מוסיפה תיקון לפי השגיאה. שגיאה מוגדרת `target - measured`. אין חובה ללמוד עכשיו את כל נוסחאות PID. נתחיל בהבנה של סימן השגיאה, מגבלות הפלט ותפקיד המדידה.

אלה מקדמי סימולציה התחלתיים, לא מקדמים לפריסה. ניסוי מסודר משנה ערך אחד בכל פעם ומשווה גרף. ערך `kP` גבוה מאוד עלול לגרום לתנודות; יעד גבוה מדי לא יושג גם אם ממשיכים להגדיל מקדמים.

## 3. ניסוי עם מדידה

הפעילו North, צפו בעליית `MeasuredRPS` ובהפרש מ־`TargetRPS`. חזרו עם יעד 10. השוו זמני הגעה ומתח. נסו בסימולציה בלבד להגדיל חיכוך, וחזרו להגדרה המקורית לפני commit.

כדי לבדוק קרבה ליעד ניתן לקרוא את הקטע הבא בתוך גוף ה־lambda של `trainingFlywheel.ifPresent`, שבו `flywheel` הוא האובייקט שקיבלנו:

```java
boolean nearTarget = flywheel.isAtVelocitySetpoint(2.0);
```

הסבילות כאן היא 2 RPS, בהתאם ליחידות שבחרנו. ערך true במחזור אחד אינו הוכחה ליציבות. בפרויקט המסכם נבקש רצף מדידות. תת־המערכת אינה מאפסת את היעד ב־disable, ולכן בודקים קרבה רק בהקשר של פקודה פעילה ומצב הרובוט.

### מה לא נכון פה?

```java
new MotorSubsystemSetVelocity<>(flywheel, () -> 1200.0)
```

התלמיד התכוון ל־1200 RPM. מה יקרה, ואיך מתקנים?

## בדיקת סיום

הציגו יעד, מדידה ושגיאה על אותו ניסוי. הסבירו מדוע בעת שחרור הפקודה מפסיקה להפעיל למרות שהיעד השמור עדיין 20. שמרו commit שמתאר את המעבר מאחוזי פלט לבקרת מהירות.
