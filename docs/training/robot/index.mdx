כבר כתבתם מחלקות, בנאים ומתודות. עכשיו נשתמש בידע הזה בתוכנית שנשארת פעילה, מקבלת קלט ומפעילה מנגנונים. נעבוד לאורך ההכשרה על אותו מאגר אישי, שנוצר מתוך [robot-template](https://github.com/Desert-Eagles-6104/robot-template).

**בסיום תוכלו למצוא את הקוד שאחראי להתנהגות, לשנות אותו, לבדוק בסימולציה ולהגיש שינוי לבדיקה.** אין צורך לייצר פרויקט WPILib חדש או להתקין את DELib בנפרד: הקוד שלה נמצא בתוך התבנית.

## איך לומדים כאן?

לפני הרצה כותבים תחזית. אחרי הרצה שומרים מדידה, ולא רק אומרים ״עובד״. כשיש פער, בודקים איזה חלק בשרשרת לא קיבל את הנתון הנכון. משתמשים ברמזים בהדרגה, ומסבירים פתרון במילים שלכם.

את הניסויים מבצעים **בסימולציה ובמאגר האישי**. מעבר לחומרה נעשה רק עם מנטור. קוד לימודי נוסף מוצג במפורש כתוספת שלכם, ולא כקוד שכבר קיים בתבנית.

אם אינכם יודעים איפה לפתוח טרמינל, לחפש קובץ או להפעיל פעולה בעורך, היעזרו ב[איך עובדים ב־VS Code](../getting-started/working-in-vscode.mdx). ההוראות אינן דורשות היכרות מוקדמת עם Git או עם תוכנות הרובוט.

אם צריך לרענן מחלקות והורשה, חזרו ל[הכשרת Java](../java/index.mdx).
