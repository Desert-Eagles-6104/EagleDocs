בזוג ה־InstantCommand היה קל לשכוח עצירה. נרצה פעולה שממשיכה כל עוד מחזיקים כפתור, ומנקה אחריה גם כשמבטלים אותה מסיבה אחרת. **פקודה מתארת פעולה לאורך זמן; תת־המערכת נשארת האובייקט שמבצע ומודד.**

### שלוש מילים לפני הקוד

**תזמון** הוא בקשה למתזמן להתחיל פקודה. **פעילה** אומר שהפקודה נמצאת ברשימת העבודה שלו והוא ממשיך לקרוא למתודות שלה. **ביטול** מוציא אותה מהרשימה ומפעיל את פעולת הסיום שלה. יצירת פקודה עם `new` לבדה עדיין אינה בקשה להתחיל אותה.

**דרישה (requirement)** אומרת שהפקודה צריכה להיות בעלת השליטה במנגנון. נבדוק בשיעור הבא מה קורה כששתי פקודות דורשות אותו מנגנון. **timeout** הוא גבול זמן שאחריו מפסיקים לחכות או לפעול; הוא אינו `sleep` שחוסם את התוכנית.

## 1. קוראים פקודה אמיתית מהמאגר

פתחו `MotorSubsystemSetPercentage` ואת מחלקת האב `MotorDoubleSupplierCommand`. בקיצור, הקוד הקיים עושה:

```java
// MotorDoubleSupplierCommand constructor
addRequirements(motorSubsystem);

// MotorSubsystemSetPercentage.execute()
this.motorSubsystem.setPercentOutput(this.valueSupplier.getAsDouble(), ignoreSoftLimits);

// MotorDoubleSupplierCommand.end(boolean interrupted)
this.motorSubsystem.disableMotors();
```

אלה קטעים מתוך מתודות שונות, לא מחלקה חדשה להדבקה. המחלקות משתמשות ב־`edu.wpi.first.wpilibj2.command.Command`.

## 2. ארבע שאלות על מחזור החיים

| מתודה              | מתי?                       | מה נבדוק?              |
| ------------------ | -------------------------- | ---------------------- |
| `initialize()`     | פעם בכל תזמון              | הכנה לפעולה            |
| `execute()`        | במחזורים שבהם הפקודה פעילה | עבודה קצרה וקלט מעודכן |
| `isFinished()`     | בדיקת סיום במהלך הריצה     | האם הפעולה הושלמה?     |
| `end(interrupted)` | בסיום או ביטול             | ניקוי ועצירת פלט       |

בפקודת האחוזים `isFinished()` מחזירה תמיד false. לכן נצטרך ביטול, למשל שחרור כפתור או timeout. פקודה יכולה להתוזמן שוב לאחר סיום; זה אינו יצירת המנגנון מחדש.

### קוראים את מקור הערך לפני השימוש

`DoubleSupplier` היא דרך לתת לפקודה פעולה שמחזירה מספר כשמבקשים אותו. בכתיבה `() -> 0.15`, הסוגריים הריקים אומרים שאין פרמטרים, והחץ אומר מה להחזיר. הערך כאן קבוע; בהמשך אפשר לקרוא ציר כדי לקבל ערך חדש. לא צריך לכתוב מחלקת Supplier משלכם.

`<>` אחרי שם מחלקת הפקודה מאפשרת ל־Java להסיק איזה סוג מנגנון נתנו לה. בתרגיל הזה משאירים את הסימון כפי שהוא; אין כאן יצירה של מנגנון נוסף.

## 3. מחליפים את השליטה הקודמת

ב־`RobotContainer` הוסיפו:

```java
import frc.DELib26.subsystems.motorSubsystems.commands.MotorSubsystemSetPercentage;
```

ב־`configureTeleopBindings()` **החליפו** את זוג ה־bindings מהשיעור הקודם:

```java
this.trainingFlywheel.ifPresent(flywheel ->
    this.driverController.northButton().whileTrue(
        new MotorSubsystemSetPercentage<>(flywheel, () -> 0.15)));
```

`DoubleSupplier` הוא אובייקט שנותן מספר כאשר מבקשים אותו. הכתיבה `() -> 0.15` נותנת אותו מספר בכל קריאה. היא אינה מריצה מיד את המנוע. `execute()` מבקשת ערך חדש בכל מחזור.

## 4. ניסוי וסיום

לחצו, החזיקו ושחררו. לאחר מכן Disable בזמן לחיצה. פקודת המנוע צריכה להתבטל, `end` צריכה לבטל פלט, והגלגל יכול לדעוך בגלל Coast. השתמשו בנתון `Subsystems/TrainingFlywheel/Command` כדי לראות איזו פקודה פעילה.

### שינוי, הרצה וחיווי

פתחו RobotContainer.java עם Ctrl + P. את ה־import החדשה מוסיפים לצד imports בראש הקובץ. בתוך `configureTeleopBindings`, מחקו **רק את זוג החיבורים של North** מהשיעור הקודם והכניסו את החיבור החדש. שמרו, בנו והפעילו מחדש.

ב־AdvantageScope חפשו `Subsystems/TrainingFlywheel/Command`. אפשר לראות ערך טקסט ברשימת הנתונים או לגרור אותו ללשונית **Table** שפותחים באמצעות `+`. בטבלה רואים נתונים לפי זמן; השם הפעיל אמור להיות `MotorSubsystemSetPercentage` בזמן החזקה ו־`None` לאחר שחרור. ייתכן פער קצר עד עדכון הטלמטריה.

| פעולה       | מה המתזמן עושה?   | מה רואים?                       |
| ----------- | ----------------- | ------------------------------- |
| תחילת לחיצה | מתחיל את הפקודה   | שם הפקודה ומהירות עולה          |
| המשך החזקה  | מפעיל execute שוב | פלט מתמשך                       |
| שחרור       | מבטל וקורא end    | Command חוזר ל־None והפלט מבוטל |

אם אחרי שחרור השם נשאר פעיל, בדקו אם השארתם `onTrue` במקום `whileTrue`. אם המהירות דועכת ולא נעצרת מיד, השוו גם למתח: Coast מאפשרת המשך סיבוב ללא פלט.

### מה לא נכון פה?

תלמיד החליף `whileTrue` ב־`onTrue`, בלי timeout ובלי ביטול אחר. מה יקרה בשחרור?

## בדיקת סיום

הסבירו מדוע לא צריך כאן `onFalse` נוסף, ובאילו שני מצבים `end(true)` צפויה להתבצע. שמרו commit שמחליף את המימוש הקודם, בלי להשאיר שתי גרסאות bindings פעילות.
