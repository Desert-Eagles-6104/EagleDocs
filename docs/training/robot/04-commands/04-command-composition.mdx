נרצה להפעיל גלגל לזמן קצר, להמתין ולעשות זאת שוב. אין צורך ב־sleep או בלולאה חוסמת: נרכיב פקודות שמחזירות שליטה למתזמן בכל מחזור.

## 1. רצף עם פקודות קיימות

ב־`RobotContainer` הוסיפו import:

```java
import edu.wpi.first.wpilibj2.command.Commands;
```

בתוך `configureTeleopBindings()`, באותה `trainingFlywheel.ifPresent`, הוסיפו:

```java
this.driverController.eastButton().onTrue(Commands.sequence(
    new MotorSubsystemSetPercentage<>(flywheel, () -> 0.15).withTimeout(1.0),
    Commands.waitSeconds(0.5),
    new MotorSubsystemSetPercentage<>(flywheel, () -> 0.20).withTimeout(1.0)
));
```

`withTimeout` מסיימת את המקטע אחרי הזמן. `end` של פקודת המנוע מבטלת את הפלט, לכן ההמתנה אינה משאירה בקשת הפעלה. הגלגל עדיין עשוי לדעוך בזמן ההמתנה.

`sequence` עוברת לפקודה הבאה רק אחרי שהקודמת הסתיימה. הקבוצה מחזיקה את איחוד הדרישות של ילדיה, גם בזמן ההמתנה. `parallel` מתחילה פעולות יחד ומסתיימת אחרי שכולן הסתיימו. אי אפשר לשים במקביל שתי פקודות שדורשות את אותו flywheel. גם `race` או `deadline` אינן דרך לעקוף קונפליקט דרישות.

אל תצרפו את אותו מופע פקודה לשתי קבוצות. צרו מופעים חדשים או factory שמחזירה פקודה חדשה, כפי שהתבנית עושה עבור אוטונומי.

## 2. מצרפים למסלול האוטונומי הקיים

`AutoProfiles` מחזירה `Map<String, AutoProfile>`. ה־`AutoProfile` מחזיק `Supplier<Command>` ותנוחת התחלה. בתוך `createAutosMap()`, לפני `return map`, הוסיפו תוספת **בסימולציה בלבד**:

```java
if (frc.DELib26.util.RunMode.isSim()) {
    map.put("Training flywheel", new AutoProfile(
        () -> {
            var flywheel = frc.robot.RobotContainer.getInstance()
                .trainingFlywheel.orElseThrow();
            return edu.wpi.first.wpilibj2.command.Commands.sequence(
                new frc.DELib26.subsystems.motorSubsystems.commands.MotorSubsystemSetPercentage<>(
                    flywheel, () -> 0.15).withTimeout(1.0),
                edu.wpi.first.wpilibj2.command.Commands.waitSeconds(0.5),
                new frc.DELib26.subsystems.motorSubsystems.commands.MotorSubsystemSetPercentage<>(
                    flywheel, () -> 0.20).withTimeout(1.0)
            );
        },
        () -> new Pose2d()
    ));
}
```

השמות המלאים כאן מאפשרים להוסיף בלי לנחש imports; אפשר לקצר עם imports ב־VS Code. אין צורך לשנות `Robot.autonomousInit()`: היא כבר מבקשת את הפקודה ומתזמנת אותה. ב־Disabled בחרו `Training flywheel` מתוך `Auto/Auto` בדשבורד, ואז עברו Autonomous ו־Enable. ברירת המחדל `Stay in place` נשארת כפי שהיא.
