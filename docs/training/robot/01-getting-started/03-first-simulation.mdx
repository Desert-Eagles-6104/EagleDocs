## לפני ההפעלה

[פתחו את הפרויקט הקיים](../../getting-started/working-in-vscode.mdx#open-project) מתוך תיקיית המאגר האישי `Moshe-robot-training` (כאשר במקום Moshe מופיע השם שלכם). ב־Explorer ודאו שרואים `build.gradle`, לא רק תיקיית `src`.

ודאו שהשלמתם את [הורדת ספריית הקבוצה](./02-template-repository.mdx#initialize-submodules) ושהבנייה הצליחה. אם עדיין לא קיבלתם `BUILD SUCCESSFUL`, חזרו ל[בנייה הראשונה ופתרון תקלות](./02-template-repository.mdx#first-build).

## מפעילים סימולציה {/* #run-simulation */}

1. שמרו את הקבצים ששיניתם.
2. לחצו **F5**, או פתחו את [חלון הפקודות](../../getting-started/working-in-vscode.mdx#command-palette) ובחרו **WPILib: Simulate Robot Code**. אם מופיעה בחירת תצורת הרצה, בחרו **WPILib Desktop Debug**.
3. אם מופיעה בחירת הרחבות, השאירו **Sim GUI** מסומנת ולחצו **OK**.
4. המתינו לסיום הבנייה ולפתיחת חלון **Robot Simulation**.

כדי להשתמש ב־[Hot Replace](#hot-replace), הפעילו במצב Debug אם מוצעת בחירה. [הוראות ההפעלה של WPILib](https://docs.wpilib.org/en/stable/docs/software/wpilib-tools/robot-simulation/introduction.html).

## מחברים שלט לסימולציה {/* #controller */}

לבדיקת מצבי הרובוט אין צורך בשלט. לפני תרגיל הכפתורים, חברו שלט USB ובצעו את החיבור הבא כשהרובוט Disabled:

1. בחלונית **System Joysticks** מצאו את השלט המחובר.
2. גררו אותו אל מקום **0** בחלונית **Joysticks**. בתבנית `driverController` משתמש בערוץ 0; הופעת השלט ברשימת המערכת לבדה אינה מחברת אותו לקוד.
3. אם השלט דורש מיפוי Gamepad, הפעילו **Map gamepad**. פתחו את פרטי `Joystick[0]`, לחצו ושחררו כפתור, וודאו שהחיווי משתנה.
4. אם החיווי אינו משתנה, בדקו את השיוך והמיפוי לפני שינוי קוד המנוע. אחרי החלפת סוג שלט עברו שוב ל־Teleop כדי שהתבנית תזהה אותו בזמן חיבור הכפתורים.

## מפסיקים את הסימולציה {/* #stop-simulation */}

לחצו על **הריבוע האדום - Stop** ב[סרגל ה־Debug](#debug-toolbar), או סגרו את טרמינל ההרצה באמצעות **אייקון הפח** ב־VS Code. כפתור ה־X שמסתיר את חלונית הטרמינל אינו מסיים את ההרצה.

## מפעילים מחדש {/* #restart-simulation */}

שמרו את שינויי הקוד ולחצו על **החץ המעגלי הירוק - Restart** ב[סרגל ה־Debug](#debug-toolbar).

אפשר גם [להפסיק את הסימולציה](#stop-simulation) ואז [להפעיל אותה שוב באמצעות F5 או חלון הפקודות](#run-simulation).
הפעלה מחדש טוענת את הקוד מחדש ומריצה שוב את קוד האתחול. השתמשו בה כשצריך להתחיל ממצב חדש, אחרי שינוי בקוד האתחול, או כאשר Hot Replace לא מצליח להחיל שינוי.

אפשר להשאיר את AdvantageScope פתוח. לאחר שהסימולציה עולה מחדש הוא מנסה להתחבר שוב אוטומטית. אם החיבור לא חוזר, בצעו שוב את [שלבי החיבור](#advantagescope).

## מעדכנים קוד עם Hot Replace {/* #hot-replace */}

**Hot Code Replace** מחיל שינויים בקוד Java בתוך הרצת Debug פעילה, בלי להפעיל את כל התוכנית מחדש. כשתשנו קוד בהמשך ההכשרה, אפשר לחזור לשלבים האלה:

1. ודאו שהסימולציה רצה באמצעות **WPILib Desktop Debug**.
2. שמרו את קובצי ה־Java ששיניתם והמתינו לסיום הקומפילציה. אם יש שגיאות, תקנו אותן קודם.
3. לחצו על **אייקון הברק - Apply Code Changes** ב[סרגל ה־Debug](#debug-toolbar) והמתינו לסיום העדכון.
4. בדקו את השינוי כשהקוד ששיניתם מופעל שוב.

Hot Replace אינו מאתחל את התוכנית ואינו מריץ מחדש בנאים או קוד שכבר הסתיים. שינויים במבנה המחלקות, כמו הוספת שדות או שינוי חתימה של מתודה, עשויים לדרוש הפעלה מחדש. אם מופיעה הודעה שהשינוי לא נתמך, [עצרו והפעילו מחדש](#restart-simulation).

אם אייקון הברק חסר, ודאו שיש הרצת Java Debug פעילה. בהגדרות VS Code, האפשרות `java.debug.settings.hotCodeReplace` צריכה להיות `manual` כדי להחיל שינויים בלחיצה; במצב `auto` הם מוחלים אוטומטית לאחר הקומפילציה. [תיעוד Hot Code Replace](https://code.visualstudio.com/docs/java/java-debugging#_hot-code-replace).

## פותחים ומחברים AdvantageScope {/* #advantagescope */}

**AdvantageScope** היא תוכנה לצפייה בנתונים שהרובוט שולח - מספרים, גרפים ומיקום על מגרש. **NetworkTables** מעביר את הנתונים מתוכנית הסימולציה אל התוכנה.

1. השאירו את הסימולציה רצה.
2. ב־VS Code פתחו את [חלון הפקודות](../../getting-started/working-in-vscode.mdx#command-palette), בחרו **WPILib: Start Tool** ואז **AdvantageScope**, אם היא מופיעה ברשימה. אפשר גם לפתוח אותה מתפריט ההתחלה של Windows. אם היא לא מותקנת, פנו למנטור והיעזרו ב[הוראות ההתקנה](https://docs.advantagescope.org/overview/installation).
3. בתוך AdvantageScope בחרו **File → Connect to Simulator → NetworkTables 4 (AdvantageKit)**. בחלק מהגרסאות שם המקור הוא **NetworkTables (AdvantageKit)**.
4. המתינו לחיבור. הכיתוב **Searching** בכותרת אומר שהתוכנה עדיין מחפשת את הסימולציה. אחרי החיבור אמורים להופיע נתונים ברשימה שבצד שמאל.
5. כדי להציג נתונים, לחצו על **+** ובחרו תצוגה כגון **Line Graph**, ואז גררו אליה נתון מספרי מרשימת הנתונים. בהמשך ההכשרה נבחר את הנתונים המתאימים לניסוי שנריץ.

**אם החיבור נשאר על Searching:** ודאו שהסימולציה עדיין רצה ושבחרתם **Connect to Simulator**. האפשרות הזאת מתחברת לסימולציה באותו מחשב, בכתובת `127.0.0.1`. אם הסימולציה נעצרה, הפעילו אותה שוב והמתינו לחיבור מחדש. [תיעוד החיבור של AdvantageScope](https://docs.advantagescope.org/overview/live-sources/).
