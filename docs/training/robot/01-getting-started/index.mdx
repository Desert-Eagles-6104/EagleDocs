נריץ את הפרויקט שקיבלנו, לפני שנוסיף מנגנון.

## לפני שמתחילים

השלימו את [הכנת סביבת העבודה](../../getting-started/index.mdx) והכינו חיבור לאינטרנט. בפרק Git ו־GitHub נבדוק את Git וניצור חשבון אם צריך. אין צורך בחיבור לרובוט פיזי.

כאן נעבוד על פרויקט רובוט נפרד מפרויקט תרגול ה־Java: ניצור מאגר מהתבנית של הקבוצה, נשכפל אותו למחשב ונריץ אותו בסימולציה.

[איך עובדים ב־VS Code](../../getting-started/working-in-vscode.mdx) הוא דף עזר שאפשר לחזור אליו בכל שלב. אין צורך להשלים אותו כשיעור מקדים.
