נרצה פרויקט אישי שמתחיל בדיוק מהקוד של הקבוצה. **Use this template יוצר מאגר חדש עם קובצי התבנית**, שאפשר לפתח בלי לשנות את מאגר המקור.

## 1. יוצרים ב־GitHub

1. פתחו [Desert-Eagles-6104/robot-template](https://github.com/Desert-Eagles-6104/robot-template), בענף `main`.
2. לחצו **Use this template → Create a new repository**. בחרו את החשבון האישי בתור Owner.
3. תנו שם כגון `robot-training`, בחרו נראות לפי הנחיית המנטור וצרו את המאגר. אם הכפתור אינו זמין, בקשו מהמנטור לבדוק שהמאגר מסומן כתבנית ושיש לכם גישה; אל תייצרו פרויקט WPILib אחר.
4. בדף המאגר החדש לחצו **Code → HTTPS** והעתיקו את הכתובת. ודאו שהבעלים בכתובת הוא אתם.

## 2. משכפלים ב־WPILib VS Code 2026

פתחו `Ctrl + Shift + P`, בחרו **Git: Clone**, הדביקו את כתובת המאגר האישי ובחרו תיקייה. פתחו את המאגר שהתקבל; אשרו Workspace Trust רק לקוד שבדקתם. אם נדרשת כניסה ל־GitHub, השלימו אותה בדפדפן.

אל תפתחו רק את `src`. בשורש צריך לראות `build.gradle`, את `gradlew` ואת `vendordeps`. המתינו לסיום ייבוא Gradle. DELib נמצאת בתוך `src/main/java/frc/DELib26`, ואין צורך להוסיף אותה כתלות חיצונית.

בדקו בטרמינל:

```bash
git status
git remote -v
```

`origin` צריך להפנות למאגר האישי. הכתובת אינה סיסמה. אל תפרסמו פלט אם הכנסתם בעבר פרטי התחברות לכתובת.

## 3. שומרים ניסוי ראשון

צרו `training-notes.md` עם שם הניסוי וציפייה אחת מהסימולציה. קראו את ה־diff בחלון Source Control, בצעו Stage לקובץ בלבד, Commit עם הודעה כגון `Add training experiment notes`, ואז Push. פתחו את GitHub וודאו שהקובץ וה־commit מופיעים.
