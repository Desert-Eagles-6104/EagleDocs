אין צורך לזכור קיצורי מקלדת או שמות של חלונות. כאן נפתח כל כלי פעם אחת ונזהה מה השתנה על המסך. אפשר לחזור לדף הזה בכל פעם שהוראה בהמשך אינה ברורה.

## 1. פותחים את התוכנה

לחצו על מקש Windows, הקלידו `WPILib VS Code 2026` ופתחו את התוצאה המתאימה. **VS Code הוא העורך שבו רואים ומשנים קוד**; החלון שנפתח אינו תוכנית הרובוט עצמה. אם התוכנה לא נמצאה, חזרו ל[בדיקת המחשב](../../getting-started/check-setup/check-setup.mdx).

## 2. פותחים טרמינל וכותבים פקודה

**טרמינל** הוא אזור שנותנים בו הוראות למחשב באמצעות טקסט. הוא נפרד מאזור קוד ה־Java: פקודה שמוצגת בבלוק `bash` או `powershell` לא מעתיקים לקובץ Java.

1. לחצו בתפריט העליון על **Terminal**, ואז **New Terminal**. בממשק שבו התפריט מוסתר תחת שלושה קווים, פתחו קודם את התפריט הזה.
2. הסתכלו בתחתית החלון: אמור להיפתח אזור עם לשונית **TERMINAL** ושורה המתחילה בדרך כלל ב־`PS`.
3. לחצו ליד הסמן המהבהב אחרי סימן `>`.
4. הקלידו `git --version`, ואז לחצו **Enter**. אם Git עדיין לא מותקן, הודעת השגיאה היא סימן לעבור לשיעור הבא ולהתקין אותו.

אפשר ללחוץ על צילום המסך כדי לפתוח אותו בגודל מלא בלשונית חדשה. זה שימושי במיוחד כשקוראים בטלפון.

**מה אמורים לראות?** שורת תשובה מתחת לפקודה, ואז שורה חדשה עם סמן. לדוגמה:

```text
git version 2.x.x.windows.x
```

ה־`x` בתמונה הזאת מסמן מספרי גרסה שמשתנים; אין להקליד את שורת התשובה. אם כתוב `not recognized`, המחשב לא מצא את Git. אם לא קרה דבר, בדקו שלחצתם Enter ושהקלדתם בטרמינל ולא בחיפוש העליון.

## 3. פותחים את חלון הפקודות

**חלון הפקודות (Command Palette)** הוא חיפוש של פעולות שהעורך יודע לבצע — למשל שכפול מאגר או הפעלת סימולציה.

1. בתפריט העליון לחצו **View → Command Palette**. חלופה: `Ctrl + Shift + P`.
2. בראש החלון מופיעה תיבת חיפוש שמתחילה ב־`>`.
3. הקלידו את שם הפעולה שהשיעור מבקש, המתינו לרשימה, לחצו על התוצאה המתאימה או בחרו אותה בחצים ולחצו Enter.
4. כדי לצאת בלי לבחור, לחצו **Esc**.

**מה אמורים לראות?** רשימת פעולות מסוננת, לא רשימת קובצי Java. `Ctrl + P` בלי Shift פותחת חיפוש **קבצים**; זה כלי אחר.

## 4. מוצאים קובץ ומקום בקוד

אחרי שנשכפל את הפרויקט, רשימת הקבצים תופיע ב־**Explorer**, האזור הצדדי של העורך. לחצו **View → Explorer** או `Ctrl + Shift + E` כדי להציג אותה.

כשהשיעור אומר לפתוח `Robot.java`:

1. לחצו `Ctrl + P`.
2. הקלידו `src/main/java/frc/robot/Robot.java` ובחרו את התוצאה עם הנתיב הזה.
3. לחצו `Ctrl + F` כדי לחפש בתוך הקובץ, והקלידו את שם המתודה, למשל `teleopInit`.
4. ודאו שרואים את הכותרת `public void teleopInit()` ואת הגוף שבין `{` ל־`}`. הוספה ״בסוף המתודה״ היא **לפני הסוגר המסיים שלה**, לא אחרי הסוגר האחרון של הקובץ.
5. אחרי שינוי לחצו `Ctrl + S`. נקודה ליד שם הלשונית מסמנת בדרך כלל שינוי שעוד לא נשמר.

## 5. יודעים איפה רואים תשובה

| פעולה                              | היכן מחפשים תוצאה?                      |
| ---------------------------------- | --------------------------------------- |
| פקודה כתובה, למשל `git --version`  | בחלונית TERMINAL מתחת לפקודה            |
| פתיחת קובץ                         | לשונית עם שם הקובץ ואזור קוד במרכז      |
| בניית קוד הרובוט                   | פלט משימת WPILib; מחפשים הצלחה או שגיאה |
| `System.out.println` בזמן סימולציה | פלט ההרצה של הסימולציה ב־VS Code        |
| שינוי שמור בקובץ                   | חלון Source Control, שנכיר בשיעור Git   |

### תרגיל: היכן מקלידים?

תלמיד העתיק `git --version` לתוך `Main.java` ומנסה לבנות את הרובוט. איך תזהו את הטעות, ולאן צריך להעביר את הפקודה?

## לפני שממשיכים

פתחו וסגרו את חלון הפקודות באמצעות Esc. הציגו את הטרמינל והצביעו על מקום ההקלדה. רק לאחר שמצאתם אותם, עברו ל[Git ו־GitHub](./01-git-and-github.mdx).
