אין צורך לזכור קיצורי מקלדת או שמות של חלונות. זהו דף עזר שאפשר לפתוח בכל שלב, לפי הצורך. אין צורך לעבור עליו לפי הסדר או להשלים אותו לפני השיעורים; הקישורים במדריכים יובילו לסעיף המתאים.

## פותחים את התוכנה {#open-vscode}

לחצו על מקש Windows, הקלידו `WPILib VS Code 2026` ופתחו את התוצאה המתאימה. **VS Code הוא העורך שבו רואים ומשנים קוד**; החלון שנפתח אינו תוכנית הרובוט עצמה. אם התוכנה לא נמצאה, חזרו ל[בדיקת המחשב](../../getting-started/check-setup/check-setup.mdx).

## טרמינל: פותחים וכותבים פקודה {#terminal}

**טרמינל** הוא אזור שנותנים בו הוראות למחשב באמצעות טקסט. הוא נפרד מאזור קוד ה־Java: פקודה שמוצגת בבלוק `bash` או `powershell` לא מעתיקים לקובץ Java.

1. לחצו בתפריט העליון על **Terminal**, ואז **New Terminal**. בממשק שבו התפריט מוסתר תחת שלושה קווים, פתחו קודם את התפריט הזה.
2. הסתכלו בתחתית החלון: אמור להיפתח אזור עם לשונית **TERMINAL** ושורה המתחילה בדרך כלל ב־`PS`.
3. לחצו ליד הסמן המהבהב אחרי סימן `>`.
4. הקלידו או הדביקו את הפקודה שמופיעה בהוראות שאתם קוראים, ואז לחצו **Enter**.

אפשר ללחוץ על צילום המסך כדי לפתוח אותו בגודל מלא בלשונית חדשה. זה שימושי במיוחד כשקוראים בטלפון.

**מה אמורים לראות?** בהתאם לפקודה, יופיע פלט או שהסמן יחזור לשורה חדשה בלי הודעה. את התוצאה הצפויה בודקים בהוראות של הפעולה שביצעתם. אם לא קרה דבר, בדקו שלחצתם Enter ושהקלדתם בטרמינל ולא בחיפוש העליון.

## חלון הפקודות {#command-palette}

**חלון הפקודות (Command Palette)** הוא חיפוש של פעולות שהעורך יודע לבצע — למשל פתיחת הגדרות או שינוי ערכת הצבעים.

1. בתפריט העליון לחצו **View → Command Palette**. חלופה: `Ctrl + Shift + P`.
2. בראש החלון מופיעה תיבת חיפוש שמתחילה ב־`>`.
3. הקלידו את שם הפעולה שהשיעור מבקש, המתינו לרשימה, לחצו על התוצאה המתאימה או בחרו אותה בחצים ולחצו Enter.
4. כדי לצאת בלי לבחור, לחצו **Esc**.

**מה אמורים לראות?** רשימת פעולות מסוננת, לא רשימת קובצי Java. `Ctrl + P` בלי Shift פותחת חיפוש **קבצים**; זה כלי אחר.

## מוצאים קובץ ומקום בקוד {#files}

רשימת הקבצים של התיקייה הפתוחה נמצאת ב־**Explorer**, האזור הצדדי של העורך. לחצו **View → Explorer** או `Ctrl + Shift + E` כדי להציג אותה. כדי לפתוח תיקייה בחרו **File → Open Folder**.

1. לחצו `Ctrl + P`.
2. הקלידו את שם הקובץ או את הנתיב שמופיע בהוראות ובחרו את התוצאה המתאימה.
3. לחצו `Ctrl + F` כדי לחפש בתוך הקובץ, והקלידו את הטקסט שאתם מחפשים.
4. אחרי שינוי לחצו `Ctrl + S`. נקודה ליד שם הלשונית מסמנת בדרך כלל שינוי שעוד לא נשמר.

## איפה רואים תשובה? {#output}

| פעולה                  | היכן מחפשים תוצאה?                                |
| ---------------------- | ------------------------------------------------- |
| הקלדת פקודה בטרמינל    | באותו טרמינל, מתחת לפקודה                         |
| פתיחת קובץ             | לשונית עם שם הקובץ ואזור העריכה במרכז             |
| הפעלת משימה מתוך העורך | בחלונית שהמשימה פתחה, בדרך כלל Terminal או Output |
| שמירת קובץ             | הנקודה ליד שם הלשונית נעלמת                       |

כדי להציג טרמינל שכבר פתוח, בחרו **View → Terminal**. אם יש כמה טרמינלים, בחרו ברשימה את זה שבו פועלת המשימה שאתם מחפשים. כדי להציג חלונית פלט בחרו **View → Output**, ואז את מקור הפלט ברשימה שלה.

## חוזרים לכאן לפי הצורך

חזרו להוראות שמהן הגעתם והמשיכו בפעולה שרציתם לבצע. אפשר לחזור לדף הזה בכל פעם שצריך למצוא כלי בעורך.
