`ControlDemo` ומעבדת הבקרה משתמשים באותה קונפיגורציה, באותם שדות ובאותו מנוע סימולציה. בדף בוחרים את ערכי ההתחלה, את היחידות, מה יופיע ואילו שדות הלומדים יוכלו לשנות.

```jsx
import ControlDemo from "@site/src/components/ControlPlayground/ControlDemo";
```

## ניסוי ממוקד

כל ערכי הניסוי נמצאים בתוך `config`. `request` מתאר את המטרה, `a` ו־`b` הם הגדרות הבקרים, ו־`compare` מפעיל השוואה. אפשר לבחור `preset` קיים ולשנות רק חלק מערכיו.

<ControlDemo
  title="מה משתנה כשמגדילים את kP?"
  preset="p"
  config={{
    duration: 8,
    a: { kp: 2 },
    graphs: ["response"],
    controls: { a: ["kp"] },
    view: { mechanism: false, step: false },
  }}
/>

## בחירת יחידות

`units.length` יכול להיות `m` או `cm`. `units.angle` יכול להיות `rad`, `rev` או `deg`. מהירות משתמשת באותה יחידה לשנייה. למשל, כשהיחידה היא `rev`, יעד `1` פירושו סיבוב אחד לשנייה בבקשת מהירות.

הערכים שכותבים בקונפיגורציה הם ביחידות שנבחרו. גם המקדמים מתייחסים לאותן יחידות. למשל, `kV = 0.6` ביחידות `rev` מוסיף 0.6 וולט לכל סיבוב לשנייה של מהירות יעד. אין צורך להכניס חישובי המרה לדף.

בבחירה אחרת של יחידות בזמן הרצה, הממשק ממיר יחד את היעד, המדידות, המקדמים והגרפים. התנועה הפיזית נשארת זהה. בתוך מנוע הסימולציה החישוב נשאר במטרים וברדיאנים.

<ControlDemo
  title="רולר במהירות סיבוב אחד לשנייה"
  config={{
    mechanism: "wheel",
    request: "velocity",
    units: { angle: "rev" },
    target: 1,
    duration: 6,
    damping: 0.6,
    inertia: 0.2,
    friction: 0.1,
    a: {
      method: "combined",
      kp: 2,
      i: false,
      d: false,
      ks: 0.1,
      kv: 0.6,
      ka: 0,
    },
    controls: { experiment: ["units", "target"], a: ["kp", "kv"] },
    graphs: ["response", "output"],
    view: { step: false },
  }}
/>

## מה אפשר לשנות?

`controls.experiment` בוחר שדות של הניסוי. `controls.a` ו־`controls.b` בוחרים שדות של כל בקר. רשימה ריקה נועלת את ההגדרות. הערך `"all"` מציג את כל השדות הרלוונטיים, בדיוק כמו במעבדה. במצב הזה ההגדרות המתקדמות מרוכזות באזור נפתח, סגור בתחילת העבודה. בבחירה מפורשת של שדות, כולם נשארים גלויים כדי שהתרגיל יהיה נגיש.

| מקום                       | שדות לבחירה                                                                                                                                                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `controls.experiment`      | `mechanism`, `request`, `units`, `target`, `demand`, `compare`, `initialVelocity`, `duration`, `speed`, `limit`, `battery`, `inertia`, `damping`, `friction`, `disturbance`, `noise`, `tolerance`, `rateTolerance`, `dwell` |
| `controls.a`, `controls.b` | `method`, `p`, `i`, `d`, `kp`, `ki`, `kd`, `antiWindup`, `ks`, `kv`, `ka`, `kg`, `output`, `hysteresis`, `low`, `high`, `profile`, `vmax`, `amax`, `jmax`, `stop`, `stopAfter`                                              |

השדות מתאימים את עצמם לשיטת הבקר ולמנגנון. למשל, `kg` מופיע במנגנון שמושפע מכבידה, ו־`kd` מופיע כשהבקר משתמש ב־D.

אפשר להציג שדה מספרי כתיבת סימון, עם ערך קבוע כשהתיבה מסומנת. למשל, הוספת רעש של 0.01 סיבובים לשנייה כשהיחידות הן `rev`.

```jsx
controls: {
  experiment: [{ key: "noise", as: "toggle", on: 0.01 }],
  a: ["kp"],
}
```

## בחירת התצוגה

| הגדרה ב־`view`   | מה מופיע                           |
| ---------------- | ---------------------------------- |
| `mechanism`      | אנימציית המנגנון                   |
| `readout`        | שגיאה ופלט נוכחיים                 |
| `settlingTime`   | זמן התייצבות מעל כל בקר            |
| `step`           | כפתור התקדמות בצעדים               |
| `speed`          | בחירת קצב ההרצה                    |
| `disturbance`    | כפתור הפרעה לחצי שנייה             |
| `tolerance`      | תחום הסבילות סביב היעד בגרף התגובה |
| `graphSelection` | תיבות לבחירת הגרפים                |
| `explanations`   | הסברי שיטת הבקר ומגבלות המודל      |

בהדגמה בדף, האנימציה וכפתור הצעדים מוצגים כברירת מחדל. שאר אפשרויות התצוגה כבויות. `graphs` בוחר את הגרפים עצמם, ואפשר לקבוע `graphs: []` כדי להציג אנימציה בלבד.

כדי להטמיע את כל אפשרויות המעבדה בתוך דף, מגדירים אותן באותה קונפיגורציה.

```jsx
<ControlDemo
  title="ניסוי חופשי"
  config={{
    controls: { experiment: "all", a: "all", b: "all" },
    view: {
      readout: true,
      settlingTime: true,
      graphSelection: true,
      explanations: true,
      speed: true,
      disturbance: true,
    },
  }}
/>
```

שינוי ערך מאתחל את הניסוי עם המקדמים שנבחרו. `initialVelocity` קובע את המהירות בתחילת כל הרצה. שינוי יחידות ממיר את הערכים המוצגים ושומר על תנאי הניסוי הפיזיים.
