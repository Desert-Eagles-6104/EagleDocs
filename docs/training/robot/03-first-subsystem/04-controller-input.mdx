ראינו שהמנוע פועל כל עוד Teleop מופעל. עכשיו נרצה התנהגות אחרת: **לחיצה תתחיל את הפעולה ושחרור יסיים אותה.** תת־המערכת תמשיך להיות אחראית למנוע ולמדידות, והפקודה תהיה אחראית לפעולה שאנחנו רוצים לבצע איתה.

**Command**, או פקודה, היא פעולה שהמתזמן מנהל לאורך זמן. אפשר להתחיל אותה, להריץ אותה במחזורים ולסיים או לבטל אותה. **Binding** הוא החיבור בין אירוע בשלט לבין פקודה.

## 1. מפנים את ההפעלה מתוך teleopPeriodic

ב־`Robot.java`, הסירו מתוך `teleopPeriodic()` את הקריאה ל־`trainingFlywheel.ifPresent(...)` שהוספנו בניסוי. השאירו את המתודה עצמה ואת כל הקוד שהיה בה לפני התרגיל. המדידות והלוגים ממשיכים להתעדכן באמצעות התשתית המוכנה.

## 2. משתמשים בפקודה מוכנה

הספרייה כבר כוללת `MotorSubsystemSetPercentage`: פקודה שמבקשת אחוז פלט בכל מחזור שבו היא פעילה, ומבטלת את הפלט כשהיא מסתיימת או מבוטלת. לא נכתוב עדיין מחלקת פקודה משלנו.

ב־`RobotContainer` הוסיפו import:

```java
import frc.DELib26.subsystems.motorSubsystems.commands.MotorSubsystemSetPercentage;
```

בתוך `configureTeleopBindings()`, לצד החיבורים הקיימים, הוסיפו:

```java
this.trainingFlywheel.ifPresent(flywheel -> {
    this.driverController.northButton().whileTrue(
        new MotorSubsystemSetPercentage<>(flywheel, () -> TrainingFlywheel.TRAINING_OUTPUT));
});
```

### קוראים את תחביר ה־lambda

בדוגמה יש שתי lambdas. המבנה שלהן הוא `פרמטרים -> פעולה`:

```java
flywheel -> {
    // קוד שמשתמש בתת־המערכת שהתקבלה
}
```

זו הפעולה שמסרנו ל־`ifPresent`. היא מקבלת פרמטר אחד, שקראנו לו `flywheel`. Java מסיקה שהוא מסוג `TrainingFlywheel` מתוך ה־`Optional<TrainingFlywheel>`. כשיש אובייקט, `ifPresent` מוסרת אותו לפעולה ומריצה את הקוד שבין הסוגריים המסולסלים. לפעולה הזאת אין ערך מוחזר.

ה־lambda השנייה נראית כך:

```java
() -> TrainingFlywheel.TRAINING_OUTPUT
```

`()` אומר שאין פרמטרים. אחרי החץ מופיע ביטוי שהערך שלו מוחזר - כאן מספר מסוג `double`. אפשר לכתוב את אותה lambda גם בצורה הארוכה:

```java
() -> {
    return TrainingFlywheel.TRAINING_OUTPUT;
}
```

הפקודה מצפה ל־`DoubleSupplier`: פעולה שאפשר לקרוא לה כדי לקבל מספר. לכן מוסרים לה את ה־lambda, ולא רק את המספר עצמו. יצירת ה־lambda אינה מפעילה את המנוע; בזמן שהפקודה רצה היא קוראת לפעולה כדי לקבל את אחוז הפלט.

### מה אומרות הסוגריים הזוויתיות?

`MotorSubsystemSetPercentage` היא מחלקה **גנרית**: היא יכולה לעבוד עם סוגים שונים של תתי־מערכות מנוע שיורשות מ־`MotorSubsystemTalon`. סוג תת־המערכת הוא פרמטר של המחלקה. במקרה שלנו הסוג הוא `TrainingFlywheel`.

אפשר לכתוב את יצירת הפקודה עם הסוג במפורש:

```java
new MotorSubsystemSetPercentage<TrainingFlywheel>(
    flywheel, () -> TrainingFlywheel.TRAINING_OUTPUT)
```

בכתיבה `new MotorSubsystemSetPercentage<>(...)`, הסימנים `<>` נקראים **diamond**. הם מאפשרים ל־Java להסיק את הסוג מהפרמטרים שהעברנו - כאן מהאובייקט `flywheel`. זו אותה בחירת סוג, בכתיבה קצרה יותר. הסוגריים `(...)` שאחריהם מכילים את הפרמטרים לבנאי: תת־המערכת והפעולה שמספקת את הפלט.

### בדקו את עצמכם

## 3. בודקים את ההתנהגות החדשה

ב־Disabled ודאו שלחיצה על הכפתור העליון משנה את החיווי בחלונית Joystick[0]. השתמשו בשלט `driverController` שכבר קיים; אין צורך ליצור שלט נוסף.

שמרו והפעילו את הסימולציה. פתחו את אותו גרף מתח ומהירות מהניסוי הקודם ובצעו:

| פעולה                       | תוצאה לבדיקה                                   |
| --------------------------- | ---------------------------------------------- |
| Enable ב־Teleop, בלי לחיצה  | אין בקשת הפעלה למנוע.                          |
| לחיצה והחזקה של North       | מופיע פלט והמהירות עולה.                       |
| שחרור הכפתור                | הפקודה מבוטלת, פלט ההנעה מתבטל והמהירות דועכת. |
| Disable בזמן לחיצה          | הפקודה אינה ממשיכה להפעיל את המנוע.            |
| שחרור ב־Disabled ואז Enable | המנוע נשאר ללא הפעלה עד לחיצה חדשה.            |

הסתכלו גם על `Subsystems/TrainingFlywheel/Command`: בזמן הפעולה אמורה להופיע הפקודה הנוכחית, ובסיומה `None`.

### לחיצה מפעילה, לחיצה נוספת עוצרת

עכשיו שנו את החיבור כך שלא צריך להחזיק את הכפתור: לחיצה אחת תתחיל את הפקודה, שחרור ישאיר אותה פעילה ולחיצה נוספת תבטל אותה.

השתמשו ב־`toggleOnTrue` במקום `whileTrue`. הפעולה בודקת בכל תחילת לחיצה אם הפקודה פעילה: אם אינה פעילה היא מתזמנת אותה, ואם היא פעילה היא מבטלת אותה. שחרור הכפתור אינו מחליף את המצב.

החליפו את החיבור הקיים, בלי להוסיף חיבור נוסף לאותו כפתור. לפני הבדיקה כתבו מה צפוי לקרות אחרי לחיצה ראשונה, שחרור, לחיצה שנייה ו־Disable. בדקו גם את המתח והמהירות וגם את שם הפקודה בלוגים.
