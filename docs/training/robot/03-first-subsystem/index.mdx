נשתמש בתת־מערכת מוכנה עם מנוע אחד כדי להבין איך קוד הופך לתנועה. נחבר אותה לרובוט, ניתן הוראה מתוך `Robot.teleopPeriodic()`, נשנה את הפלט ונראה את התוצאה בלוגים ובגרף. לאחר מכן נעביר את ההפעלה ל־Commands כדי לבחור מתי המנוע עובד.

## לפני שמתחילים

המשיכו במאגר האישי מההכשרה הקודמת. ודאו שאפשר להריץ סימולציה ולהתחבר אליה עם AdvantageScope. הקובץ `TrainingFlywheel.java` צריך להגיע מוכן בריפו ההכשרות.
