# מכינים את המחשב לעבודה 🛠️

לפני שנכתוב קוד, נכין את התוכנות שבהן נשתמש לאורך ההכשרה ובעבודה בצוות התוכנה.

כאן נבדוק מה כבר מותקן, נשלים את מה שחסר ונכיר את סביבת העבודה. לא צריך להכיר את התוכנות מראש - ההוראות יובילו אתכם צעד אחר צעד.

## מה צריך להיות במחשב?

| כלי | למה נשתמש בו? |
| --- | --- |
| **WPILib VS Code 2026** | סביבת העבודה שבה נפתח פרויקטים, נערוך קוד ונריץ אותו |
| **Java JDK** | כלי הפיתוח שמאפשרים לבנות ולהריץ תוכניות Java; הוא כלול בהתקנת WPILib |

## איך מתקדמים?

1. **בודקים את המחשב.** יכול להיות שחלק מהתוכנות כבר מותקנות, במיוחד במחשב של הקבוצה.
2. **משלימים רק את מה שחסר.** אם בדיקה לא מצליחה, יהיה קישור להוראות המתאימות. פתחו אותן בלשונית חדשה, בצעו את ההוראות וחזרו לבדיקה שממנה הגעתם.
3. **ממשיכים עד לסיום הבדיקה.** בסוף דף הבדיקה נוודא שהשלמנו את ההכנה, ומשם נעבור ליצירת פרויקט Java ראשון.

במהלך העבודה נסביר גם איך לפתוח את התוכנות ואיפה להקליד את פקודות הבדיקה. אין צורך לזכור הכול מראש.

:::tip התוכנות כבר מותקנות?
גם אם המחשב נראה מוכן, עברו על הבדיקה הקצרה כדי לוודא שהגרסה המתאימה מותקנת ושהכלים זמינים. אם הכול עובד, תוכלו להמשיך בלי לבצע התקנות נוספות.
:::
