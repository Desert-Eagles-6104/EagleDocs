לפעמים המצלמה מזהה מטרה ולפעמים אין מטרה בתמונה. **`Optional`** היא מחלקה מ־`java.util` שמייצגת את שתי האפשרויות במפורש. בהגדרה `Optional<T>`, הפרמטר `T` מציין את טיפוס הערך שעשוי להיות בפנים. ב־`Optional<String>` בחרנו ב־`String`, ולכן התוצאה יכולה להכיל טקסט או להיות ריקה. ## 1. מחזירים ערך קיים או תוצאה ריקה

בפרויקט Java שלכם צרו את התיקייה `src/enrichment` אם היא עדיין לא קיימת, ואת הקובץ `OptionalDemo.java` בתוכה. הריצו אותו כדי לראות תוצאה של שתי קריאות מדומות למצלמה.

```java
package enrichment;

import java.util.Optional;

public class OptionalDemo {
    public static void main(String[] args) {
        Optional<String> detected = findTarget(true);
        Optional<String> missing = findTarget(false);

        System.out.println(detected.isPresent());         // true
        System.out.println(missing.isPresent());          // false
        System.out.println(detected.orElse("No target")); // Tag 7
        System.out.println(missing.orElse("No target"));   // No target
    }

    static Optional<String> findTarget(boolean visible) {
        if (visible) {
            return Optional.of("Tag 7");
        }
        return Optional.empty();
    }
}
```

`Optional.of(...)` עוטפת ערך שקיים. `Optional.empty()` מחזירה תוצאה ריקה. כשמקבלים ערך מממשק אחר והוא עשוי להיות `null`, אפשר להשתמש ב־`Optional.ofNullable(...)`, שמחזירה `Optional` ריקה עבור `null`.

`isPresent()` מחזירה `true` כשהערך קיים ו־`false` כשהתוצאה ריקה. `orElse(...)` מחזירה את הערך הקיים או את ברירת המחדל שנתנו לה. לכן שתי הקריאות עם אותה ברירת מחדל נותנות תוצאות שונות.

### תרגיל 1: מה יודפס?

בתוך `main` החליפו את `findTarget(false)` ב־`findTarget(true)` בשורה שמגדירה את `missing`. נחשו מה יודפס בשורות שקוראות ל־`isPresent()` ול־`orElse(...)` על `missing`. הריצו כדי לבדוק ואז החזירו את `false` לקראת התרגיל הבא.

## 2. בוחרים איך להשתמש בתוצאה

| רוצים | משתמשים ב־ |
| --- | --- |
| לבצע פעולה כשהערך קיים | `ifPresent(...)` |
| לקבל ערך או להשתמש בברירת מחדל | `orElse(...)` |
| לבדוק קיום כחלק מתנאי `if` | `isPresent()` |
| לקבל ערך שחייב להיות קיים בשלב הזה | `orElseThrow()` |

`ifPresent(...)` מעבירה את הערך לפעולה אם הוא קיים. בתוך `main` אפשר לנסות את הקטע הבא. הלמבדה תדפיס `Tag 7` עבור `detected` ותופעל רק בשורה הראשונה. [קוראים את תחביר הלמבדה שב־`ifPresent`](../09-lambdas/index.mdx)

```java
detected.ifPresent(target -> System.out.println(target));
missing.ifPresent(target -> System.out.println(target));
```

`orElseThrow()` מחזירה את הערך כשהוא קיים וזורקת `NoSuchElementException` כשה־`Optional` ריקה. השתמשו בה כשקיום הערך כבר נבדק או כשהיעדרו מעיד על שגיאה. בדוגמה הבאה בודקים שיש זיהוי לפני ששולפים את שם המטרה.

```java
if (detected.isPresent()) {
    String target = detected.orElseThrow();
    System.out.println("Selected: " + target);
}
```
