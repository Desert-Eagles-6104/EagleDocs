אחרי שיעורי החובה, שמסתיימים ב־[Generics](../08-generics/index.mdx) וב־[Lambda](../09-lambdas/index.mdx), אפשר להמשיך להכשרת הרובוט. את הנושאים כאן אפשר ללמוד לפי הצורך, כשפוגשים אותם בקוד של הרובוט או של הספרייה.

- [המחלקה `Optional`](./01-optional.mdx) ממשיכה את שיעור Generics ומראה איך מייצגים ערך שעשוי להיות חסר.
- [ערכים מוגדרים מראש (`enum`)](./02-enums.mdx) מייצגים בחירה מתוך רשימה קבועה של אפשרויות.
- [ממשקים (`interface`)](./03-interfaces.mdx) מגדירים אילו פעולות כמה מחלקות מציעות לקוד שמשתמש בהן.

להמשך המסלול עברו ל[הכשרת הרובוט](../../robot/index.mdx).
