## 1. מתחילים ממה שכבר מכירים

השאירו ב־`Robot.java` את השדות:

```java
public class Robot {
    public String name;
    public double speed;
}
```

עד עכשיו האצנו את הרובוט כך, בתוך `main`:

```java
Robot robot = new Robot();
robot.speed = 0.25;
robot.speed = robot.speed + 0.25;
```

אם נרצה להאיץ כמה פעמים או כמה רובוטים, נחזור על הפעולה. במקום לכתוב את הפעולה בכל מקום, אפשר להגדיר אותה בתוך `Robot`.

## 2. מתודה שמשתמשת בשדה

הוסיפו **בתוך המחלקה `Robot`**, מתחת לשדות:

```java
public void accelerate(double amount) {
    speed = speed + amount;
}
```

את הפרמטרים ואת `void` כבר פגשנו במתודות. מה שחדש כאן הוא שהמתודה משתמשת בשדה `speed` של האובייקט שעליו מפעילים אותה.

כך משתמשים בה, בתוך `main`:

```java
Robot robot = new Robot();
robot.speed = 0.25;
robot.accelerate(0.25);
System.out.println(robot.speed);
```

הפלט יהיה `0.5`: המתודה הוסיפה `0.25` למהירות שהייתה `0.25`.

:::note[ומה עם static?]
השאירו את `public static void main(String[] args)` כפי שהוא. למתודות שאנחנו מוסיפים ל־`Robot` כתבו `public` ללא `static`, כמו בדוגמאות: נרצה להפעיל אותן על אובייקט מסוים. נלמד את ההבדל לעומק בנפרד.
:::

## 3. על איזה רובוט המתודה פועלת?

```java
Robot first = new Robot();
Robot second = new Robot();
first.speed = 0.25;
second.speed = 0.5;

first.accelerate(0.25);
```

הקריאה היא `first.accelerate(...)`, לכן המתודה משנה את המהירות של האובייקט שאליו `first` מפנה. המהירות של השני נשארת `0.5`.

**אותה הגדרת מתודה משמשת את כל האובייקטים, אבל כל קריאה פועלת על השדות של האובייקט שנבחר.**

## 4. מתודה בלי פרמטרים

נוסיף פעולה שעוצרת את הרובוט:

```java
public void stop() {
    speed = 0;
}
```

ובתוך `main`:

```java
robot.stop();
```

גם כשאין פרמטרים, צריך סוגריים. `robot.speed` ניגש לשדה; `robot.stop()` מפעיל מתודה.

אפשר גם להדפיס מידע מתוך מתודה:

```java
public void printStatus() {
    System.out.println(name);
    System.out.println(speed);
}
```

## 5. מתודה שמחזירה מידע

לא כל מתודה משנה את האובייקט. אפשר להחזיר את המהירות:

```java
public double getSpeed() {
    return speed;
}
```

ואפשר להחזיר תשובה לשאלה:

```java
public boolean isMoving() {
    return speed != 0;
}
```

כאן נגדיר ״בתנועה״ בתוכנית הלימודית שלנו כ־`speed` שאינו אפס. זו אינה מדידה של רובוט פיזי.

בתוך `main`:

```java
double currentSpeed = robot.getSpeed();
boolean moving = robot.isMoving();
System.out.println(currentSpeed);
System.out.println(moving);
```

| המתודה | מה היא עושה? | מה היא מחזירה? |
| --- | --- | --- |
| `accelerate(amount)` | משנה את המהירות | כלום (`void`) |
| `stop()` | משנה את המהירות לאפס | כלום (`void`) |
| `printStatus()` | מדפיסה שם ומהירות | כלום (`void`) |
| `getSpeed()` | קוראת את המהירות | `double` |
| `isMoving()` | בודקת אם המהירות שונה מאפס | `boolean` |

### תרגיל 6: בונים לבד

הרחיבו את `Robot.java` מהחלק הקודם. ודאו שיש בו `accelerate(double amount)`, `stop()`, `printStatus()`, `getSpeed()` ו־`isMoving()`.

ב־`Main` צרו שני רובוטים חדשים עם שמות שונים. תנו לראשון מהירות `0.25` ולשני `0.75`. האיצו את הראשון ב־`0.25`, עצרו את השני והדפיסו את המצב של שניהם באמצעות `printStatus()`.

לפני ההרצה, כתבו על דף את המהירות הצפויה של כל אחד.

<ExerciseHelp
  hints={["כל מתודה צריכה להיות בתוך Robot, אבל מחוץ למתודות האחרות.", "ב־Main, שימו לב למשתנה שלפני הנקודה בכל קריאה.", "שתי הקריאות האחרונות צריכות להיות first.printStatus() ו־second.printStatus()."]}
  solution={`// Robot.java
public class Robot {
    public String name;
    public double speed;

    public void accelerate(double amount) {
        speed = speed + amount;
    }

    public void stop() {
        speed = 0;
    }

    public void printStatus() {
        System.out.println(name);
        System.out.println(speed);
    }

    public double getSpeed() {
        return speed;
    }

    public boolean isMoving() {
        return speed != 0;
    }
}

// Main.java - קובץ נפרד
public class Main {
    public static void main(String[] args) {
        Robot first = new Robot();
        Robot second = new Robot();
        first.name = "Eagle";
        first.speed = 0.25;
        second.name = "Falcon";
        second.speed = 0.75;
        first.accelerate(0.25);
        second.stop();
        first.printStatus();  // Eagle ואז 0.5
        second.printStatus(); // Falcon ואז 0.0
    }
}`}
  solutionLanguage="java"
  multipleSolutions={true}
/>

## לפני שממשיכים: בדקו את עצמכם

הוסיפו ל־`Robot` מתודה `doubleSpeed()` שמכפילה את מהירותו פי שניים. צרו שני אובייקטים, הפעילו אותה רק על אחד ובדקו את שניהם.

הסבירו: איך המתודה יודעת באיזה שדה `speed` להשתמש? מה ההבדל בין שינוי השדה, הדפסתו והחזרתו באמצעות `return`?

**שמרו את המחלקה.** בחלק הבא נשנה את הדרך שבה יוצרים אובייקט ומגדירים את המצב ההתחלתי שלו.
