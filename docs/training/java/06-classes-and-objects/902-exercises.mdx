# תרגול מחלקות ואובייקטים

בפרק הזה נחבר כמעט את כל מה שלמדנו עד עכשיו: משתנים, תנאים, מתודות, פרמטרים, `return`, הגדרות גישה (`public` ו-`private`), בנאים (Constructors), יצירת אובייקטים באמצעות `new`, עבודה עם כמה קבצים ואובייקטים בתוך אובייקטים.

**חשוב: זה פרויקט אחד שנבנה בהדרגה.** בתרגילים 1–7 תיצרו מחלקות ותשפרו אותן. **אל תמחקו את הקבצים בין התרגילים!** בתרגיל 8 תחברו את כל המחלקות למערכת אחת. אפשר לשנות את `Main.java` בין התרגילים כדי לבצע בדיקות, אבל שמרו את קובצי המחלקות.

:::info עד כמה זה דומה לתכנות רובוט אמיתי?
אנחנו בונים **הדמיה לימודית** של חלקים ברובוט: מנועים, חיישנים ומערכות. בקוד הזה שינוי שדה בשם `speed` **לא באמת מפעיל מנוע**, וקריאה לחיישן מחזירה ערך ששמרנו בתוכנה - לא מדידה מחומרה.

ברובוט FRC אמיתי משתמשים ב-**WPILib** ובספריות של יצרני החומרה כדי לדבר עם מנועים וחיישנים, לנהל מערכות (Subsystems) ולהפעיל פקודות (Commands). המבנה והקוד שונים, אבל העקרונות שאתם לומדים כאן - מחלקות, אובייקטים והרכבת מערכות - הם בדיוק הבסיס שתצטרכו שם. בהמשך תעשו את זה עם רובוט אמיתי, וזה הרבה יותר מגניב!
:::

**איך עובדים?** בכל תרגיל נסו קודם לבד. אם נתקעתם, פתחו רמז אחד בכל פעם. אחרי הרמזים תוכלו לראות פתרון מלא ולהשוות לקוד שלכם.

## תרגיל 1 - מחלקת Motor

צרו קובץ חדש בשם `Motor.java`, באותה תיקייה שבה נמצא `Main.java`.

### א. יצירת המחלקה

צרו מחלקה ציבורית בשם `Motor`.

### ב. הוספת שדה

הוסיפו למחלקה שדה:

```java
private double speed;
```

### ג. Constructor

צרו בנאי שיקבע את המהירות ההתחלתית ל-`0`.

### ד. שינוי מהירות

צרו מתודה `public void setSpeed(double speed)` שתשמור את המהירות החדשה בשדה.

### ה. קבלת מהירות

צרו מתודה `public double getSpeed()` שתחזיר את המהירות.

### ו. שימוש מתוך `Main`

בתוך `main` שבקובץ `Main.java`, צרו `Motor`, שנו את מהירותו ל-`0.6` והדפיסו את המהירות בעזרת ה-Getter.

<ExerciseHelp
  hints={[
    "הפרידו בין הגדרת המחלקה ב-Motor.java לבין יצירת האובייקט בתוך main. הבנאי חייב להיקרא בדיוק כמו המחלקה.",
    "מכיוון שהשדה speed פרטי, Main לא אמור לשנות אותו ישירות. השתמשו ב-setSpeed וב-getSpeed.",
    "לפרמטר של setSpeed ולשדה יש אותו שם. השתמשו ב-this.speed כדי לציין את השדה של האובייקט. בתוך main יוצרים אובייקט בעזרת new Motor()."
  ]}
  solution={`// Motor.java
public class Motor {
    private double speed;

    public Motor() {
        speed = 0;
    }

    public void setSpeed(double speed) {
        this.speed = speed;
    }

    public double getSpeed() {
        return speed;
    }
}

// Main.java (בקובץ נפרד)
public class Main {
    public static void main(String[] args) {
        Motor motor = new Motor();
        motor.setSpeed(0.6);
        System.out.println(motor.getSpeed());
    }
}`}
multipleSolutions={true}
/>

**שמרו את `Motor.java`!** נשתמש בו שוב בתרגילים 2, 4, 5, 6, 7 ו-8. הקוד בפתרון מציג שני קבצים נפרדים - אין לשים שתי מחלקות `public` באותו קובץ.

## תרגיל 3 - מחלקת Sensor

צרו קובץ חדש בשם `Sensor.java` **לצד `Motor.java`**, בלי למחוק אותו.

### ד. Getter

### ה. בדיקה

## תרגיל 4 - Intake

עכשיו נחבר כמה מחלקות. צרו קובץ בשם `Intake.java`, **והשאירו את `Motor.java` ואת `Sensor.java` בפרויקט**.

המחלקה `Intake` תכיל שני שדות פרטיים:

```java
private Motor motor;
private Sensor sensor;
```

### א. Constructor

בבנאי של `Intake` צרו מנוע וחיישן באמצעות `new` ושמרו אותם בשדות.

### ב. הפעלת המנגנון

צרו מתודה `public void run()` שמגדירה למנוע מהירות `0.7`.

### ג. עצירת המנגנון

צרו מתודה `public void stop()` שמגדירה את המהירות ל-`0`.

### ד. בדיקת Game Piece

צרו מתודה `public boolean hasGamePiece()` שמחזירה את מצב החיישן.

### ה. עדכון אוטומטי

צרו `public void update()`:

- אם החיישן פעיל, קראו ל-`stop()`.
- אחרת, קראו ל-`run()`.

<ExerciseHelp
  hints={[
    "הפעם שדה במחלקה הוא אובייקט של מחלקה אחרת. השתמשו ב-Motor וב-Sensor שכבר יצרתם, ולא הגדירו אותם מחדש.",
    "run ו-stop צריכות לקרוא ל-setSpeed על המנוע. hasGamePiece צריכה להחזיר את התוצאה של sensor.isActive().",
    "בתוך update השתמשו ב-if (hasGamePiece()) וב-else. אפשר לקרוא ישירות למתודות run() ו-stop() מתוך אותה מחלקה."
  ]}
  solution={`// Intake.java
public class Intake {
    private Motor motor;
    private Sensor sensor;

    public Intake() {
        motor = new Motor();
        sensor = new Sensor();
    }

    public void run() {
        motor.setSpeed(0.7);
    }

    public void stop() {
        motor.setSpeed(0);
    }

    public boolean hasGamePiece() {
        return sensor.isActive();
    }

    public void update() {
        if (hasGamePiece()) {
            stop();
        } else {
            run();
        }
    }
}`}
multipleSolutions={true}
/>

כאן אנחנו **מדמים** קליטת Game Piece: החיישן מחזיק ערך שנקבע בתוכנה. ברובוט אמיתי משתמשים בחיישן מתאים ובספרייה שמאפשרת לקרוא את מצבו. **שמרו את `Intake.java`** - בתרגיל הבא נשנה את הבנאי שלו.

## תרגיל 5 - העברת אובייקטים ל-Constructor

עד עכשיו `Intake` יצר בעצמו `Motor` ו-`Sensor`. עכשיו נשנה את **אותו `Intake.java` מתרגיל 4** כך שיקבל אובייקטים מבחוץ. אל תשמרו שתי גרסאות שונות של המחלקה בשם `Intake` באותה תיקייה.

### א. שינוי Constructor

במקום בנאי שלא מקבל פרמטרים ויוצר אובייקטים בעצמו, כתבו בנאי שמקבל `Motor motor` ו-`Sensor sensor`.

### ב. שמירת האובייקטים

שמרו אותם בשדות בעזרת `this`.

### ג. שימוש מתוך `Main`

בתוך `main` צרו:

```java
Motor intakeMotor = new Motor();
Sensor intakeSensor = new Sensor();
Intake intake = new Intake(intakeMotor, intakeSensor);
```

### ד. בדיקה

שנו את `intakeSensor` ל-`true`, קראו ל-`intake.update()` והדפיסו את מהירות `intakeMotor`. מה אתם מצפים לראות? כדי להבחין בשינוי, תוכלו גם לקרוא קודם ל-`intake.run()`.

<ExerciseHelp
  hints={[
    "המטרה היא להעביר ל-Intake את האובייקטים שכבר נוצרו ב-main, ולא ליצור בתוכו מנוע וחיישן חדשים.",
    "הבנאי צריך לקבל שני פרמטרים מטיפוסים Motor ו-Sensor. בשמירתם השתמשו ב-this.motor וב-this.sensor.",
    "ב-main הפעילו intake.run(), אחר כך intakeSensor.setActive(true) ואז intake.update(). כש-hasGamePiece() מחזירה true, update עוצרת את המנוע."
  ]}
  solution={`// Intake.java - גרסה מעודכנת
public class Intake {
    private Motor motor;
    private Sensor sensor;

    public Intake(Motor motor, Sensor sensor) {
        this.motor = motor;
        this.sensor = sensor;
    }

    public void run() {
        motor.setSpeed(0.7);
    }

    public void stop() {
        motor.setSpeed(0);
    }

    public boolean hasGamePiece() {
        return sensor.isActive();
    }

    public void update() {
        if (hasGamePiece()) {
            stop();
        } else {
            run();
        }
    }
}

// בתוך main שב-Main.java
Motor intakeMotor = new Motor();
Sensor intakeSensor = new Sensor();
Intake intake = new Intake(intakeMotor, intakeSensor);

intake.run();
intakeSensor.setActive(true);
intake.update();
System.out.println(intakeMotor.getSpeed()); // 0.0`}
multipleSolutions={true}
/>

**למה זה עובד?** גם `Main` וגם `Intake` מחזיקים הפניות **לאותם אובייקטים**. שינוי החיישן ב-`Main` משפיע על מה שה-`Intake` קורא. שמרו את הגרסה המעודכנת של `Intake.java` לתרגילים הבאים.

## תרגיל 6 - Drivetrain

צרו קובץ חדש `Drivetrain.java`. **אל תמחקו את מחלקות `Motor`, `Sensor` ו-`Intake`**.

ב-`Drivetrain` הגדירו שני שדות פרטיים:

```java
private Motor leftMotor;
private Motor rightMotor;
```

### א. Constructor

צרו את שני המנועים בתוך הבנאי.

### ב. נסיעה

צרו `public void drive(double leftSpeed, double rightSpeed)` שמגדירה מהירות שונה לכל מנוע.

### ג. עצירה

צרו `public void stop()` שמגדירה את שני המנועים ל-`0`.

### ד. Getters

צרו `public double getLeftSpeed()` ו-`public double getRightSpeed()`.

### ה. בדיקה

בתוך `main`, צרו `Drivetrain`, קראו ל-`drive(0.5, 0.8)`, והדפיסו את שתי המהירויות. נסו גם לקרוא ל-`stop()` ולהדפיס שוב.

<ExerciseHelp
  hints={[
    "Drivetrain מחזיקה שני אובייקטים מאותה מחלקה. לכל מנוע צריך להיות שדה וערך משלו.",
    "ב-drive הפעילו setSpeed על כל מנוע עם הפרמטר המתאים. ב-stop הגדירו 0 לשניהם.",
    "ב-getLeftSpeed וב-getRightSpeed החזירו את הערך בעזרת getSpeed של המנוע המתאים. בדקו ש-stop מאפסת את שני הערכים."

  solution={`// Drivetrain.java
public class Drivetrain {
    private Motor leftMotor;
    private Motor rightMotor;

    public Drivetrain() {
        leftMotor = new Motor();

        leftMotor.setSpeed(leftSpeed);
        rightMotor.setSpeed(rightSpeed);
    }

    public void stop() {
        leftMotor.setSpeed(0);
        rightMotor.setSpeed(0);
    }

    public double getLeftSpeed() {
        return leftMotor.getSpeed();
    }

    public double getRightSpeed() {
        return rightMotor.getSpeed();
    }
}

drivetrain.drive(0.5, 0.8);
System.out.println(drivetrain.getLeftSpeed());  // 0.5
System.out.println(drivetrain.getRightSpeed()); // 0.8

drivetrain.stop();
System.out.println(drivetrain.getLeftSpeed());  // 0.0
System.out.println(drivetrain.getRightSpeed()); // 0.0`}
multipleSolutions={true}
/>

:::note סימולציה לעומת רובוט אמיתי
המחלקה הזו שומרת שני ערכי מהירות בלבד. היא לא שולטת במנועים פיזיים ולא מדמה את כל התנהגות הרובוט. ב-FRC אפשר להשתמש ב-WPILib ובבקרי מנועים אמיתיים, ולעיתים גם במערכות הנעה מורכבות הרבה יותר, כמו Swerve. כרגע אנחנו מתרגלים איך **מערכת אחת מנהלת כמה אובייקטים**.
:::

## תרגיל 10 - אתגר מסכם: Arm

בנו מחלקה חדשה בשם `Arm.java`. **השתמשו ב-`Motor.java` וב-`Sensor.java` ששמרתם** - אל תעתיקו לתוכה את קוד המחלקות האלו.

המערכת צריכה לעמוד בדרישות הבאות:

1. ל-`Arm` יהיה שדה פרטי מסוג `Motor` ושדה פרטי מסוג `Sensor`.
2. הבנאי יקבל את שניהם כפרמטרים וישמור אותם בשדות.
3. תהיה מתודה `public void move(double speed)`.
4. אם החיישן פעיל **והמהירות המבוקשת חיובית**, המנוע יעצור (מהירות `0`).
5. אחרת המנוע יקבל את המהירות שנשלחה.
6. תהיה מתודה `public double getSpeed()` שמחזירה את מהירות המנוע.
7. בתוך `Main`, צרו `Motor`, `Sensor` ו-`Arm` שמעבירים אליו את שני האובייקטים.
8. הפעילו את `move` עם כמה ערכים שונים, שנו את מצב החיישן ובדקו את התוצאות.

<ExerciseHelp
  hints={[
    "חשבו על המבנה של Intake מתרגיל 5: גם כאן מחלקה אחת מחזיקה Motor ו-Sensor ומקבלת אותם מבחוץ דרך הבנאי.",
    "ההחלטה אם לעצור נעשית בתוך move. דרושים שני תנאים שמתקיימים יחד: sensor.isActive() וגם speed > 0.",
    "כשהתנאי מתקיים, קראו ל-motor.setSpeed(0). אחרת השתמשו ב-motor.setSpeed(speed). ב-Main בדקו מצב חיישן false ואז true, ונסו מהירויות חיוביות ושליליות."
  ]}
  solution={`// Arm.java
public class Arm {
    private Motor motor;
    private Sensor sensor;

    public Arm(Motor motor, Sensor sensor) {
        this.motor = motor;
        this.sensor = sensor;
    }

    public void move(double speed) {
        if (sensor.isActive() && speed > 0) {
            motor.setSpeed(0);
        } else {
            motor.setSpeed(speed);
        }
    }

    public double getSpeed() {
        return motor.getSpeed();
    }
}

// Main.java (קובץ נפרד)
public class Main {
    public static void main(String[] args) {
        Motor armMotor = new Motor();
        Sensor armSensor = new Sensor();
        Arm arm = new Arm(armMotor, armSensor);

        arm.move(0.5);
        System.out.println(arm.getSpeed()); // 0.5

        armSensor.setActive(true);
        arm.move(0.5);
        System.out.println(arm.getSpeed()); // 0.0

        arm.move(-0.5);
        System.out.println(arm.getSpeed()); // -0.5
    }
}`}
multipleSolutions={true}
/>
