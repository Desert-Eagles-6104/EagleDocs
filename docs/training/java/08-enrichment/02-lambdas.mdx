פקודת מנוע יכולה לבקש מהשלט ערך חדש בכל מחזור. כדי לאפשר זאת, מוסרים לה פעולה שקוראת את הערך כשהפקודה צריכה אותו. **ביטוי למבדה (lambda)** הוא דרך קצרה לכתוב פעולה כזאת.

**בסוף השיעור תוכלו לקרוא ביטוי למבדה ולהסביר מתי הגוף שלו רץ ואיזה ערך הוא מחזיר.**

## 1. הטיפוס קובע מה הפעולה מקבלת ומחזירה

למבדה מתאימה ל**ממשק פונקציונלי**, ממשק שדורש מימוש למתודה אחת. גוף הלמבדה מספק את המימוש שלה. נשתמש בשני ממשקים מוכנים מ־`java.util.function`. [ממשקים ב־Java](./01-interfaces.mdx)

| טיפוס | מה הפעולה מקבלת? | מה הפעולה מחזירה? | איך קוראים לה? |
| --- | --- | --- | --- |
| `DoubleSupplier` | בלי פרמטרים | `double` | `getAsDouble()` |
| `DoubleConsumer` | `double` אחד | `void` | `accept(value)` |

החץ `->` מפריד בין רשימת הפרמטרים לבין גוף הפעולה. `()` משמשת לפעולה בלי פרמטרים. כשיש פרמטר אחד ו־Java מסיקה את טיפוסו מהממשק, אפשר לכתוב רק את השם שלו. כשגוף שמחזיר ערך הוא ביטוי אחד, ערך הביטוי מוחזר. בגוף שמוקף ב־`{ }` כותבים `return` כדי להחזיר ערך.

```java
DoubleSupplier fixedOutput = () -> 0.15;
DoubleConsumer reportOutput = output -> System.out.println(output);
```

השורה הראשונה שומרת פעולה שמספקת `0.15`. השנייה שומרת פעולה שמדפיסה את המספר שקיבלה. כדי להפעיל אותן אפשר לכתוב `reportOutput.accept(fixedOutput.getAsDouble())`.

## 2. מתי קוראים את הערך?

בתוך `src/enrichment` בפרויקט Java שלכם צרו את `LambdaDemo.java` והריצו אותו.

```java
package enrichment;

import java.util.function.DoubleConsumer;
import java.util.function.DoubleSupplier;

public class LambdaDemo {
    private static double requestedOutput = 0.15;

    public static void main(String[] args) {
        double savedOutput = requestedOutput;
        DoubleSupplier initialOutput = () -> savedOutput;
        DoubleSupplier currentOutput = () -> requestedOutput;
        DoubleConsumer reportOutput = output -> System.out.println(output);

        requestedOutput = 0.30;
        reportOutput.accept(initialOutput.getAsDouble());
        reportOutput.accept(currentOutput.getAsDouble());
    }
}
```

```text
0.15
0.3
```

בשתי הלמבדות גוף הפעולה רץ רק כשקוראים ל־`getAsDouble()`. `initialOutput` קוראת ערך מקומי שנשמר מראש, ואילו `currentOutput` קוראת את השדה המעודכן בזמן הקריאה. למבדה יכולה להשתמש במשתנה מקומי מבחוץ כשהוא מקבל ערך פעם אחת ואינו משתנה בהמשך.

## 3. מפנים למתודה שכבר קיימת {#method-references}

כשכל הפעולה היא קריאה למתודה קיימת, אפשר לפעמים להשתמש ב**הפניה למתודה** עם `::`. נסו להחליף את ההגדרה של `reportOutput` בשורה הבאה.

```java
DoubleConsumer reportOutput = System.out::println;
```

`reportOutput.accept(...)` מעבירה את המספר ל־`println` גם בכתיבה הזאת.

## בדיקת סיום

הוסיפו ל־`main` משתנה `DoubleSupplier` בשם `limitedOutput`. בתוך גוף הלמבדה קראו את `requestedOutput`, הגבילו אותו מלמעלה ל־`0.20` בעזרת `Math.min` והחזירו את התוצאה. שנו את השדה אחרי הגדרת הלמבדה ובדקו את הפעולה ב־`0.10` וב־`0.45`.
