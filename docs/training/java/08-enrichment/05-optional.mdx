לפעמים המצלמה מזהה מטרה ולפעמים אין מטרה בתמונה. **`Optional`** היא מחלקה מ־`java.util` שמייצגת את שתי האפשרויות במפורש. `Optional<String>` יכולה להכיל טקסט או להיות ריקה.

**בסוף השיעור תוכלו ליצור `Optional`, לפעול כשהערך קיים ולבחור מה לעשות כשהוא חסר.**

## 1. מחזירים ערך קיים או תוצאה ריקה

בתוך `src/enrichment` בפרויקט Java שלכם צרו את `OptionalDemo.java`. התוכנית מדמה שתי קריאות למצלמה.

```java
package enrichment;

import java.util.Optional;

public class OptionalDemo {
    public static void main(String[] args) {
        Optional<String> detected = findTarget(true);
        Optional<String> missing = findTarget(false);

        detected.ifPresent(target -> System.out.println(target));
        missing.ifPresent(target -> System.out.println(target));
        System.out.println(missing.orElse("No target"));
    }

    static Optional<String> findTarget(boolean visible) {
        if (visible) {
            return Optional.of("Tag 7");
        }
        return Optional.empty();
    }
}
```

`Optional.of(...)` עוטפת ערך שקיים. `Optional.empty()` מחזירה תוצאה ריקה. כשמקבלים ערך מממשק אחר והוא עשוי להיות `null`, אפשר להשתמש ב־`Optional.ofNullable(...)`, שמחזירה `Optional` ריקה עבור `null`.

`ifPresent(...)` מעבירה את הערך לפעולה אם הוא קיים. בדוגמה היא מדפיסה את `Tag 7` בשורה הראשונה ומדלגת על הפעולה עבור `missing`. `orElse(...)` מחזירה את הערך הקיים או את ברירת המחדל שנתנו לה, ולכן ההדפסה האחרונה היא `No target`. [קוראים את תחביר הלמבדה שב־`ifPresent`](./02-lambdas.mdx)

## 2. בוחרים איך להשתמש בתוצאה

| רוצים | משתמשים ב־ |
| --- | --- |
| לבצע פעולה כשהערך קיים | `ifPresent(...)` |
| לקבל ערך או להשתמש בברירת מחדל | `orElse(...)` |
| לבדוק קיום כחלק מתנאי `if` | `isPresent()` |
| לקבל ערך שחייב להיות קיים בשלב הזה | `orElseThrow()` |

`orElseThrow()` מחזירה את הערך כשהוא קיים וזורקת `NoSuchElementException` כשה־`Optional` ריקה. השתמשו בה כשקיום הערך כבר נבדק או כשהיעדרו מעיד על שגיאה. למשל, בשיעור הרובוט בודקים שהרולר קיים לפני יצירת פקודה ששולפת אותו.

```java
if (detected.isPresent()) {
    String target = detected.orElseThrow();
    System.out.println("Selected: " + target);
}
```
