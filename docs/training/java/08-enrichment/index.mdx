אפשר להתחיל את הכשרת הרובוט אחרי שיעורי היסוד של Java. את הנושאים כאן אפשר ללמוד לפי הצורך, כשפוגשים אותם בקוד של הרובוט או של הספרייה. כל דוגמה רצה בפרויקט Java רגיל.

- [ממשקים (`interface`)](./01-interfaces.mdx) — מגדירים אילו פעולות כמה מחלקות מציעות לקוד שמשתמש בהן.
- [ביטויי למבדה](./02-lambdas.mdx) — מעבירים פעולה שאפשר לקרוא לה מאוחר יותר.
- [טיפוסים גנריים](./03-generics.mdx) — משתמשים באותה מחלקה עם טיפוסים שונים.
- [ערכים מוגדרים מראש (`enum`)](./04-enums.mdx) — מייצגים בחירה מתוך רשימה קבועה של אפשרויות.
- [המחלקה `Optional`](./05-optional.mdx) — מציינים שערך עשוי להיות חסר ומחליטים מה לעשות בכל מצב.

להמשך המסלול עברו ל[הכשרת הרובוט](../../robot/index.mdx).
