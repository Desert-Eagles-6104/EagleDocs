תוכנה שמחליטה אם הרובוט קרוב למכשול צריכה לקבל מרחק. לפעמים המרחק מגיע מחיישן, ולפעמים נרצה לתת לתוכנה ערך קבוע לצורך בדיקה. איך מאפשרים לשני מקורות המרחק לעבוד עם אותו קוד?

**בסוף השיעור תוכלו להגדיר ממשק, לממש אותו במחלקה ולהשתמש באובייקט דרך טיפוס הממשק.**

## 1. מגדירים את הפעולה המשותפת

**ממשק (`interface`)** מגדיר אילו פעולות יהיו זמינות לקוד שמשתמש בו. נתחיל מממשק עם פעולה אחת שמחזירה מרחק בסנטימטרים. בפרויקט Java שלכם צרו את התיקייה `src/enrichment` ואת הקובץ `DistanceSensor.java` בתוכה.

```java
package enrichment;

public interface DistanceSensor {
    double readDistanceCm();
}
```

ההכרזה קובעת את שם המתודה, את סוג ההחזרה ואת הפרמטרים שלה. כאן המתודה מסתיימת בנקודה־פסיק כי הממשק משאיר את המימוש למחלקה. הפעולה נחשבת `public`, גם כשהמילה אינה כתובה בהכרזה.

## 2. מממשים את הממשק במחלקה

באותה תיקייה צרו את `PracticeDistanceSensor.java`. המילה `implements` אומרת שהמחלקה מספקת את הפעולות שהממשק דורש.

```java
package enrichment;

public class PracticeDistanceSensor implements DistanceSensor {
    @Override
    public double readDistanceCm() {
        return 42.0;
    }
}
```

`@Override` מאפשרת ל־Java לבדוק שהמתודה אכן מתאימה להכרזה בממשק. המתודה במחלקה היא `public` כדי שקוד שמשתמש בממשק יוכל לקרוא לה.

## 3. משתמשים בטיפוס הממשק

צרו את `InterfaceDemo.java` והריצו אותו.

```java
package enrichment;

public class InterfaceDemo {
    public static void main(String[] args) {
        DistanceSensor sensor = new PracticeDistanceSensor();
        printDistance(sensor);
    }

    static void printDistance(DistanceSensor sensor) {
        System.out.println(sensor.readDistanceCm());
    }
}
```

`printDistance` יכולה לקבל אובייקט מכל מחלקה שמממשת `DistanceSensor`. הטיפוס `DistanceSensor` קובע איזו מתודה זמינה בקוד. בזמן הריצה Java מפעילה את המימוש של האובייקט שקיבלה בפועל, ולכן כאן יודפס `42.0`.
