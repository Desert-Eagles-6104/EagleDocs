נרצה מחלקה ששומרת מדידה. לפעמים המדידה היא מספר ולפעמים היא תיאור בטקסט. **טיפוסים גנריים** מאפשרים לכתוב מחלקה אחת ולבחור את טיפוס הערך כשמשתמשים בה.

**בסוף השיעור תוכלו להסביר מה מציינים הסוגריים הזוויתיים, לקרוא `<>` בבנאי ולהבין מגבלה כמו `T extends Number`.**

## 1. כותבים מחלקה עם פרמטר של טיפוס

בתוך `src/enrichment` בפרויקט Java שלכם צרו את `Reading.java`.

```java
package enrichment;

public class Reading<T> {
    private final T value;

    public Reading(T value) {
        this.value = value;
    }

    public T getValue() {
        return value;
    }
}
```

`<T>` אחרי שם המחלקה מכריז על **פרמטר של טיפוס**. השם `T` מייצג את הטיפוס שנבחר עבור השדה, הפרמטר בבנאי והערך המוחזר מ־`getValue()`.

## 2. בוחרים טיפוס כשמשתמשים במחלקה

צרו את `GenericsDemo.java` והריצו אותו.

```java
package enrichment;

public class GenericsDemo {
    public static void main(String[] args) {
        Reading<String> status = new Reading<String>("Ready");
        Reading<Double> voltage = new Reading<>(6.5);

        String message = status.getValue();
        double volts = voltage.getValue();
        System.out.println(message);
        System.out.println(volts);
    }
}
```

| כתיבה | איך קוראים אותה? |
| --- | --- |
| `Reading<String>` | מדידה שערכה מסוג `String` |
| `Reading<Double>` | מדידה שערכה מסוג `Double` |
| `new Reading<>(6.5)` | יוצרים מדידה ונותנים ל־Java להסיק את הטיפוס לפי ההכרזה והערך שנמסר לבנאי |

`<>` בביטוי `new` נקרא **diamond**. כאן Java מסיקה `Double`. בסוגריים הזוויתיים משתמשים בטיפוס אובייקט. `Double` היא המחלקה שעוטפת ערך `double`, ו־Java ממירה ביניהם אוטומטית בדוגמה. למספרים שלמים יש עטיפה מקבילה בשם `Integer`.

## 3. מגבילים אילו טיפוסים מתאימים

נניח שנרצה לקרוא לכל מדידה כמספר עשרוני. אפשר להגביל את `T` ל־`Number` ולמחלקות שיורשות ממנה, כגון `Integer` ו־`Double`. צרו את `NumericReading.java`.

```java
package enrichment;

public class NumericReading<T extends Number> {
    private final T value;

    public NumericReading(T value) {
        this.value = value;
    }

    public double asDouble() {
        return value.doubleValue();
    }
}
```

`T extends Number` מבטיח שכל ערך מהטיפוס `T` יציע את המתודות של `Number`. לכן אפשר לקרוא כאן ל־`doubleValue()`.
