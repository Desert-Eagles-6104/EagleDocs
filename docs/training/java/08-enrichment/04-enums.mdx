לרובוט יש מצב נהיגה רגיל ומצב נהיגה מדויקת. אם נשמור את המצב כטקסט, שגיאת כתיב עדיין תיתן לנו `String` תקינה. **`enum`** מגדיר טיפוס עם רשימת ערכים קבועה מראש, ו־Java בודקת שהערך שבחרנו שייך לרשימה.

**בסוף השיעור תוכלו להגדיר `enum`, להשוות בין הערכים שלו ולשמור נתון לכל ערך.**

## 1. מגדירים רשימת מצבים

בתוך `src/enrichment` בפרויקט Java שלכם צרו את `DriveMode.java`.

```java
package enrichment;

public enum DriveMode {
    NORMAL,
    PRECISION
}
```

`NORMAL` ו־`PRECISION` הם שני ערכים של `DriveMode`. בקוד בוחרים ערך בעזרת שם הטיפוס ונקודה, למשל `DriveMode.PRECISION`.

## 2. משתמשים בערכים בתוכנית

צרו את `EnumDemo.java` והריצו אותו.

```java
package enrichment;

public class EnumDemo {
    public static void main(String[] args) {
        DriveMode mode = DriveMode.PRECISION;

        if (mode == DriveMode.PRECISION) {
            System.out.println("Precision mode");
        }

        for (DriveMode availableMode : DriveMode.values()) {
            System.out.println(availableMode.name());
        }
    }
}
```

משווים ערכי `enum` באמצעות `==`. המתודה `values()` מחזירה את כל הערכים לפי סדר ההכרזה. הלולאה מפעילה את גוף ההדפסה פעם אחת לכל ערך, ו־`name()` מחזירה את השם כפי שנכתב בקוד.

## 3. שומרים נתון לכל ערך

לכל מצב נהיגה נוכל לצרף אחוז פלט מרבי. החליפו את התוכן של `DriveMode.java` בגרסה הבאה.

```java
package enrichment;

public enum DriveMode {
    NORMAL(0.80),
    PRECISION(0.30);

    private final double maxOutput;

    DriveMode(double maxOutput) {
        this.maxOutput = maxOutput;
    }

    public double getMaxOutput() {
        return maxOutput;
    }
}
```

המספר בסוגריים של כל ערך מועבר לבנאי. הנקודה־פסיק אחרי הערך האחרון מפרידה בין רשימת הערכים לבין השדה והמתודות. נסו להדפיס את `mode.getMaxOutput()` בתוך `main`.
