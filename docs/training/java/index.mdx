# ברוכים הבאים להכשרות התוכנה! 🤖

ברוכים הבאים להכשרות התוכנה של **Desert Eagles 6104**!

כאן תלמדו את כל מה שצריך כדי להתחיל לתכנת, להבין איך תוכנה עובדת, ובהמשך גם לכתוב קוד לרובוט של הקבוצה.

**לא צריך ניסיון קודם בתכנות.** ההכשרה מתחילה מהיסודות, וכל נושא חדש מתבסס על מה שכבר למדתם.

במהלך ההכשרה לא רק נקרא הסברים, אלא גם נכתוב קוד, נפתור תרגילים ונבנה בהדרגה תוכניות שמדמות מערכות של רובוט אמיתי.

:::tip המטרה שלנו
בסיום ההכשרה תוכלו להבין ולכתוב קוד ב-Java, לעבוד עם מחלקות ואובייקטים ולהיות מוכנים להתחיל ללמוד כיצד מתכנתים את הרובוט באמצעות WPILib.
:::

---

## 🗺️ מה נלמד?

ההכשרה מחולקת לכמה שלבים, כאשר כל שלב מכין אותנו לשלב הבא.

### 1. יסודות Java

נתחיל בלימוד שפת Java, שבה אנחנו משתמשים כדי לתכנת את הרובוט.

נלמד:
- משתנים וסוגי נתונים
- תנאים וקבלת החלטות
- לולאות
- פונקציות ופרמטרים
- עבודה עם קלט ופלט

כבר בשלב הזה נכתוב תוכניות שמדמות פעולות של הרובוט, כמו חישוב מהירות מנוע, בדיקת נתוני חיישנים וקבלת החלטות.

### 2. תכנות מונחה עצמים (OOP)

רובוט מורכב ממערכות שונות, וגם התוכנה שלו צריכה להיות מאורגנת בהתאם.

נלמד:
- מחלקות ואובייקטים
- שדות ומתודות
- בנאים (Constructors)
- שימוש במחלקות מתוך מחלקות אחרות
- הורשה ועקרונות נוספים של תכנות מונחה עצמים

נשתמש בידע הזה כדי ליצור מחלקות המדמות מנועים, חיישנים ומערכות שלמות של הרובוט.

### 3. מתכנתים את הרובוט

אחרי שנרכוש בסיס טוב ב-Java, נתחיל ללמוד איך משתמשים בו ברובוט אמיתי.

נכיר את WPILib, את מבנה פרויקט הרובוט ואת הדרך שבה הקוד שולט במערכות השונות.

:::info
ההכשרה מתפתחת בהדרגה. חלק מהנושאים והתרגילים יתווספו בהמשך.
:::

## 💻 מכינים את סביבת העבודה

לפני שמתחילים לכתוב קוד, צריך לוודא שהמחשב שלנו מוכן.

במהלך ההכשרה נשתמש בכמה כלים:

| תוכנה | למה היא משמשת? |
|---|---|
| **Java JDK** | מאפשרת לקמפל ולהריץ קוד Java |
| **Visual Studio Code** | סביבת העבודה שבה נכתוב ונריץ את הקוד |
| **Extension Pack for Java** | מוסיף ל-VS Code תמיכה בפיתוח Java |
| **Git** | משמש לניהול גרסאות ולעבודה עם פרויקטים משותפים |

:::tip כבר התקנתם הכול?
אם התוכנות כבר מותקנות אצלכם, אפשר לדלג על ההתקנה ולעבור ישירות לבדיקות שבהמשך.
:::

### עדיין לא התקנתם?

הכנו מדריך שמסביר כיצד להתקין ולהגדיר את סביבת העבודה, שלב אחר שלב.

**[📥 למדריך התקנת סביבת העבודה](/docs/java-setup)**

לאחר שסיימתם את ההתקנה, חזרו לעמוד הזה כדי לבדוק שהכול עובד.

## ✅ בודקים שהמחשב מוכן

לפני שמתחילים את ההכשרה, נוודא שהכלים שהתקנו עובדים.

### בדיקה 1 — Java

1. פתחו את PowerShell או את שורת הפקודה (CMD).
2. הקלידו את הפקודה הבאה:

```powershell
java -version
```

אם Java מותקנת ומוגדרת כראוי, תופיע הודעה שמציגה את הגרסה שלה.

לדוגמה:

```text
openjdk version "17.0.x"
```

:::note
מספר הגרסה אצלכם יכול להיות שונה. חשוב לוודא שאתם משתמשים בגרסת Java הנדרשת להכשרה.
:::

אם מופיעה הודעה שהפקודה לא זוהתה, חזרו למדריך ההתקנה.

### בדיקה 2 — Visual Studio Code

1. פתחו את VS Code.
2. לחצו על סמל ההרחבות (Extensions) בצד המסך.
3. חפשו `Extension Pack for Java`.
4. ודאו שההרחבה מותקנת ומופעלת (Enabled).

### בדיקה 3 — Git

פתחו את הטרמינל והקלידו:

```powershell
git --version
```

אם Git מותקן, יופיע מספר הגרסה שלו.

### בדיקה 4 — מריצים את תוכנית ה-Java הראשונה!

עכשיו נבדוק שאנחנו באמת יכולים לכתוב ולהריץ קוד.

1. פתחו את VS Code.
2. צרו תיקייה חדשה ופתחו אותה ב-VS Code.
3. צרו בתוכה קובץ בשם `Main.java`.
4. הדביקו את הקוד הבא:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Desert Eagles!");
    }
}
```

5. לחצו על כפתור ההרצה (Run) שמופיע מעל המתודה `main`, או על כפתור ההרצה המתאים ב-VS Code.

אם הכול עובד, אתם אמורים לראות:

```text
Hello, Desert Eagles!
```

🎉 **מזל טוב! הרצתם את תוכנית ה-Java הראשונה שלכם!**

:::warning לא מצליחים להריץ?
ודאו ששמרתם את הקובץ בשם `Main.java`, שהתקנתם את הרחבות Java וש-VS Code מזהה את ה-JDK.

אם עדיין יש בעיה, בקשו עזרה מהמדריך.
:::

## 📚 איך עובדים עם ההכשרה?

כל נושא בהכשרה כולל הסברים, דוגמאות קוד ותרגילים שיעזרו לכם ליישם את מה שלמדתם.

כדי להפיק מההכשרה כמה שיותר:

1. **קוראים ומבינים** — אל תמהרו להעתיק את הדוגמאות. נסו להבין מה כל שורה עושה.
2. **מריצים ומשנים** — נסו לשנות את הקוד ולראות כיצד התוצאה משתנה.
3. **פותרים את התרגילים** — כתבו את הפתרונות בעצמכם. אל תסתפקו בלקרוא פתרון מוכן.
4. **שואלים כשצריך** — אם משהו לא ברור, נסו להבין מה לא עובד ופנו למדריך לעזרה.
5. **מתקדמים בהדרגה** — ודאו שאתם מבינים נושא לפני שאתם עוברים לנושא הבא.

:::important
**המטרה היא לא רק לגרום לקוד לעבוד, אלא גם להבין למה הוא עובד.**

בהמשך תעבדו על קוד של רובוט אמיתי, ולכן חשוב שתדעו לקרוא, להבין ולתקן קוד באופן עצמאי.
:::
