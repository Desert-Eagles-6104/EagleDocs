# מתחילים לכתוב קוד 🤖

ברוכים הבאים להכשרת Java של **Desert Eagles 6104**!

איך גורמים לרובוט לנסוע כשלוחצים על כפתור? או לעצור כשהוא מזהה משהו בדרך? בשביל זה צריך לכתוב לו קוד - הוראות שאומרות לו מה לעשות.

בהכשרה הזאת נלמד לכתוב קוד בשפת Java. נתחיל בתוכניות קטנות שרצות במחשב, ובהדרגה נבנה את הידע שיעזור לנו לתכנת את הרובוט של הקבוצה. **לא צריך ניסיון קודם - מתחילים מההתחלה.**

## איך זה ייראה?

התוכנית הראשונה שלנו תציג הודעה על המסך. אחר כך נלמד לעשות חישובים ולגרום לתוכנית לעשות דברים שונים לפי המצב. לאורך הדרך נתרגל עם דוגמאות שקשורות לרובוט של הקבוצה.

בכל שלב תכתבו קוד בעצמכם, תריצו אותו ותראו מה קורה. לא צריך להבין הכול מיד - נתקדם צעד אחר צעד.

## איך לומדים כאן?

- **מנסים בעצמנו:** קוראים את ההסבר, כותבים את הדוגמה ומריצים אותה.
- **בודקים מה משתנה:** מנסים לנחש מה יקרה, משנים משהו קטן בקוד ומריצים שוב.
- **מתרגלים:** מנסים לפתור את התרגילים לפני שפותחים רמז או פתרון.
- **לומדים גם מטעויות:** אם מופיעה שגיאה, קוראים את ההודעה ובודקים מה צריך לתקן. זה חלק רגיל מתכנות.
- **שואלים כשצריך:** המנטור וחברי הצוות כאן כדי לעזור. אתם לא צריכים להסתדר עם הכול לבד.
