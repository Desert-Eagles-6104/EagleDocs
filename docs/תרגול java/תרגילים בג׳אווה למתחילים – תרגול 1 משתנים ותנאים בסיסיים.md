## תרגילים על משתנים
1. הכרז משתנים מסוג `int`, `double` ו-`String`. אתחל אותם בערכים לבחירתך והדפס למסך.
2. כתוב תכנית שמחשבת את הסכום של שני מספרים ומדפיסה את התוצאה.
3. כתוב תכנית שמחשבת את שטח מלבן לפי רוחב וגובה שמוזנים על ידי המשתמש.
4. המר מספר שלם של שניות לדקות ושניות (לדוגמה, 125 שניות → 2 דקות ו-5 שניות).
5. כתוב תכנית שמקבלת שם משתמש ומדפיסה הודעת `שלום <שם>`.
## תרגילים על תנאים
1. כתוב תכנית שמקבלת מספר ובודקת אם הוא חיובי, שלילי או אפס.
2. כתוב תכנית שבודקת אם מספר הוא זוגי או אי-זוגי.
3. כתוב תכנית שבודקת אם שנה היא שנה מעוברת.
4. כתוב תכנית שמקבלת שני מספרים ומדפיסה את הגדול ביניהם.
5. כתוב תכנית שמקבלת שלושה ציונים ומדפיסה אם התלמיד עבר (ממוצע מעל 55).

## תרגילי אתגר
1. כתוב תכנית שמקבלת גיל ומדפיסה אם המשתמש **ילד**, **נער** או **מבוגר** לפי טווחים שאתה בוחר.
2. כתוב תכנית שמקבלת שלושה מספרים ומדפיסה את הגדול מביניהם.
3. כתוב תכנית שמקבלת טמפרטורה ומדפיסה `קר`, `נעים` או `חם` לפי הערך.
4. כתוב תכנית שמקבלת שם משתמש וסיסמה ובודקת אם הם תואמים לערכים שמוגדרים מראש.
## טיפ למבנה תכנית בסיסית בג׳אווה
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        // דוגמה: קריאת מספר
        System.out.print("הכנס מספר: ");
        int x = in.nextInt();

        // דוגמה: תנאי בסיסי
        if (x > 0) {
            System.out.println("חיובי");
        } else if (x < 0) {
            System.out.println("שלילי");
        } else {
            System.out.println("אפס");
        }

        in.close();
    }
}
```
