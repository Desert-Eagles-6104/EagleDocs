## מה המחלקה עושה {#what-this-class-does}

`MechanismSim` היא לולאת סימולציה קטנה למנגנונים מונעי מנוע, כמו זרוע, מעלית, מפרק קצה או גליל.

במצב SIM, CTRE/Phoenix עדיין מחשב את **המתח המבוקש למנוע** לפי הבקרה שלכם בחוג סגור, אבל נדרש משוב מחיישנים כדי לסגור את החוג בפועל. המחלקה משלימה את המשוב החסר:

1. קוראת מ־Phoenix את **המתח המבוקש בהדקי המנוע**.
2. מזינה את המתח הזה ל־**מודל פיזיקלי של המנגנון** ב־WPILib (`LinearSystemSim`).
3. מקדמת את המודל בזמן באמצעות אינטגרציה לאורך `dt`.
4. מעדכנת את סימולציית ה־TalonFX במיקום ובמהירות של **הרוטור** שהתקבלו (`setRawRotorPosition`, `setRotorVelocity`).
5. מעתיקה את אותו מצב חיישן לכל מנועי ה־followers.

## הרעיון המרכזי: יחידות רוטור לעומת יחידות מנגנון {#key-idea-rotor-units-vs-mechanism-units}

המתודות שמעדכנות חיישנים בסימולציית Phoenix מקבלות ערכים ב־**יחידות רוטור**:

- מיקום: **סיבובים**.
- מהירות: **סיבובים לשנייה (RPS)**.

לכן, אם המודל שלכם עוקב אחר המיקום והמהירות של *המנגנון*, צריך להמיר אותם ליחידות רוטור לפני שמחזירים אותם מהמתודות:

- `getSimulatedRotorPositionRotations()`
- `getSimulatedRotorVelocityRPS()`

---

## תזמון הסימולציה {#timing-model}

`Notifier` מפעיל את הסימולציה במחזוריות:

- זמן המחזור הוא `config.simPeriodSec`, בדרך כלל `0.005` שניות עבור תדר של 200 Hz.

כך משתפרת יציבות הבקרה בחוג סגור בסימולציה, במחיר של שימוש רב יותר ב־CPU.

## הלולאה הראשית: מה קורה בכל מחזור {#main-loop-what-happens-every-tick}

זו הלוגיקה המרכזית, לאחר צמצום לחלקים החשובים:

```java
protected void updateSimState() {
    var simState = this.masterIO.getSimState();

    double busVolts = RobotController.getBatteryVoltage();
    simState.setSupplyVoltage(busVolts);

    double simVoltage = this.addFriction(simState.getMotorVoltage(), this.frictionVoltage);

    this.sim.setInput(simVoltage);

    double dt = this.timestampDeltaCalculator.update();
    sim.update(dt);

    this.manualRotorPositionOverride.get()
        .ifPresent(pos -> this.setSimulatedRotorPositionRotations(pos));

    double rotorPosition = this.getSimulatedRotorPositionRotations();
    double rotorVel = this.getSimulatedRotorVelocityRPS();

    double rotorAcceleration = (rotorVel - this.lastRotorVelocityRPS) / dt;
    this.lastRotorVelocityRPS = rotorVel;

    simState.setRawRotorPosition(rotorPosition);
    simState.setRotorVelocity(rotorVel);
    simState.setRotorAcceleration(rotorAcceleration);

    for (SimTalonFXIO follower : this.followerIOs) {
        var st = follower.getSimState();
        st.setSupplyVoltage(busVolts);
        st.setRawRotorPosition(rotorPosition);
        st.setRotorVelocity(rotorVel);
        st.setRotorAcceleration(rotorAcceleration);
    }
}
```

יצירת מחלקה יורשת

צריך לממש את המתודות הבאות:

protected abstract double getSimulatedRotorPositionRotations();
protected abstract double getSimulatedRotorVelocityRPS();

מתודה שאפשר לדרוס לפי הצורך; מימוש ברירת המחדל שלה כרגע אינו עושה דבר:

protected void setSimulatedRotorPositionRotations(double rotorPositionRotations) {}

דוגמה: המרת מצב המודל מיחידות מנגנון ליחידות רוטור

נניח שמצב המודל נמדד בסיבובי המנגנון, ויחס התמסורת הוא `sensorPerMechanismRatio`, כלומר מספר סיבובי הרוטור לכל סיבוב של המנגנון:

```java
public class ArmSim extends MechanismSim<N2, N1, N1> {
    private final double sensorPerMechanismRatio;

    public ArmSim(
        LinearSystemSim<N2, N1, N1> sim,
        MechanismSimConfig config,
        SimTalonFXIO master,
        SimTalonFXIO[] followers,
        double sensorPerMechanismRatio
    ) {
        super(sim, config, master, followers);
        this.sensorPerMechanismRatio = sensorPerMechanismRatio;
    }

    @Override
    protected double getSimulatedRotorPositionRotations() {
        double mechanismRot = /* read from your sim state */;
        return mechanismRot * sensorPerMechanismRatio;
    }

    @Override
    protected double getSimulatedRotorVelocityRPS() {
        double mechanismRps = /* read from your sim state */;
        return mechanismRps * sensorPerMechanismRatio;
    }
}
```

מודל חיכוך פשוט שאפשר להוסיף לפי הצורך

`addFriction(voltage, frictionVoltage)` מחילה אזור מת שמדמה בקירוב חיכוך קולון:

- אם |V| < frictionVoltage, הפלט הוא 0.
- אחרת, מפחיתים את השפעת החיכוך בכיוון התנועה.

```java
protected double addFriction(double motorVoltage, double frictionVoltage) {
    if (Math.abs(motorVoltage) < frictionVoltage) return 0.0;
    if (motorVoltage > 0.0) return motorVoltage - frictionVoltage;
    return motorVoltage + frictionVoltage;
}
```

אפשר לכוון את החיכוך בזמן הריצה:

mechanismSim.setFrictionVoltage(0.4); // volts

דגשים ודברים שכדאי לשים לב אליהם

- **Threads**: `Notifier` פועל ב־thread נפרד. אל תבצעו פעולות חוסמות בתוך `updateSimState()`.
- **יציבות `dt`**: אם `dt` הוא $\approx$ 0, התאוצה המחושבת עלולה לגדול מאוד. `TimestampDeltaCalculator` צריך למנוע מצב כזה, או שצריך להגביל את `dt` לערך מינימלי.
- **Followers**: מנועי ה־followers מקבלים את אותם אותות חיישן מדומים כמו מנוע ה־master, כמקובל ב־FRC.
