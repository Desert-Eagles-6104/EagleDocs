# DELib

DELib מרכזת קוד משותף למערכות הרובוט: חיבור לרכיבים, פעולות מנועים, מדידות וסימולציה. בפרויקט ההכשרה היא נמצאת תחת `src/main/java/frc/DELib26` ומנוהלת כ־Git submodule. הפרויקט מפנה לגרסה מסוימת שלה; עדכון עצמאי של הספרייה עלול לשנות את הממשק שההסברים מסתמכים עליו.

## כשדוגמה אינה מתאימה לקוד שלכם

בדקו תחילה את שם החבילה, חתימת המתודה וגרסת הספרייה שבפרויקט. קוד המקור שב־submodule הוא הקובע עבור הבנייה שלכם. השוו גם יחידות, סוג בקשת בקרה ותנאי סיום; שתי מתודות עם שמות דומים אינן בהכרח מבקשות את אותה פעולה.
